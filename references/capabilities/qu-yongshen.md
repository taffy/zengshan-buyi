# 取用神（事类→爻）

> capability_id: `cap.zengshanbuyi.qu-yongshen`
> 来源：f03 / f04 / f14(side) / x05 / x08 / x15 / x19 / x22 / c01 / c02 / c03 / c04 / c05 / c24

## R — Reading（原文）

**段一｜卷一《用神章第八》（父母爻、官鬼爻两条）**

> 父母爻：占父母即以卦中之父母爻为神。……占天地、城池、墙垣，宅舍、屋宇，舟车、衣服、雨具、绸缎，布匹、章奏、文书及书馆文契也以父母爻为用神，物类亦多在变通，一切庇护我身者是也。
> 官鬼爻：占功名、官府、雷霆鬼神、妻占夫皆以官鬼爻为用神。占乱臣贼盗、邪崇也以官鬼爻为用神，物类亦多，一切拘束我身者是也

**段二｜卷二《两现章》第三十二 ＋ 卷二《飞伏神章》第二十八**

> 用神两现……舍其休囚，用其旺相，舍其静爻，而用动爻，舍其月破，而用不破，舍其旬空，用其不空……此古法也。得其验者，应乎旬空月破，舍其不空，而用旬空，舍其不破，而用月破。
> 野鹤曰：何必如此？用神衰败则祸福已知矣，为何不再占一卦合断？余于用神不现，即有伏神亦不用之，再占两卦用神必现。

## I — Interpretation（自述）

这套体系要解决的只有一件事：这张卦单上的六个爻里，哪一个代表我要问的这件事。做法不是逐个打分，而是先把眼前的事归进五个类别之一，再去找挂着那个标签的爻。

五个类别的划分依据很特别——作者不看物件的名称和外形，只看它在我的处境里充当什么功能：

- **父母**：一切起到遮护、承载、凭据作用的东西。长辈师长是一类人，房屋车船衣服雨具是一类物，奏章文书契约又是另一类物，三者的共同点是都在护着我。
- **官鬼**：一切起到约束、管束、压迫作用的东西。功名官府、雷霆鬼神、盗贼邪祟都在这一类；妻子问丈夫也落在这一爻上，那是当时的伦理语境。
- **兄弟**：与我同类却要分我之利的人。它还有几个"兼职"身份：问钱财时它是夺财之神，问谋事时它是梗阻之神，问妻妾仆役时它是刑伤克害之神。
- **妻财**：我所驱使的人，以及一切归我使用的财物。注意这一个标签同时罩住了人和物，这是当时社会结构的投影，不是中性技术。
- **子孙**：家族中处在晚辈位置的人，再外加医药、僧道、兵卒、六畜一类。它同时是制伏鬼祟之神、解除忧患之神、剥去官职之神——所以几乎所有事碰上它都算喜庆，唯独求官求名要回避它，因为它克官。

书里没列过的新事类，就问自己"这东西在我这件事里扮演哪个角色"，按上面五条归类，**不要按名词去查表**。

真正选爻时会撞上三种局面。第一种，卦里同类标签出现了两个或三个：常规做法是挑处境最强的一个（旺相的、发动的、既不落空也不落破的），但作者本人反复得到相反的经验——真正给出答案的常常是那个落空或者落破的爻，因为要找的并不是最有劲的那个，而是**能指明时间的那个**；空待出空、破待实破，应期就从这个爻上生出来。第二种，卦里一个这类标签都没有：先看当时的月建、日辰能不能顶上，若能就直接用；若也不能，**不许回头去翻伏神、互卦那一层层的补救办法**，规矩是干脆再摇一卦合参。第三种，是代别人来问：卦对应的是"谁的念头"，别人代问的卦里，这一步根本无从下手。

最后一条要害：**同一个爻会因为问的事不同而翻转吉凶**。问官职，挂着官鬼标签的那个爻是喜的信号；换成问这一年顺不顺，同一个位置立刻变成了忌的信号。所以在选用神之前，问的那句话必须先钉死。

## A1 — Past Application（书中案例）

**其一｜代长辈问功名，作者当场拒绝取用神，改从整体变化直断寿数（c01，卷一《卦变生克墓绝章》第二十四）**
- 遇到什么问题：来人不肯说明事由，只丢一句"替长辈问功名"。既属于代人开口，又是长辈，两层关系都不清楚。
- 怎么用这个方法论：作者先声明此路不通——"功名须要亲占，代占难取用神，从不敢断"，拒绝按常规往下选爻；转而走整体变化的路线，本卦巽木化成乾金，是回头克过来的格局，属于绝卦。
- 得出什么结论：不必再问功名，断其寿命不长。
- 实际结果如何：果于削职之后七个月身故。

**其二｜卦里两个妻财，反取落空的那个（c02，卷二《两现章》第三十二）**
- 遇到什么问题：未月庚子日问求财，卦中两处挂着妻财标签，一处临月建且克世、一处持世而落旬空。按旧例应取旺而不空的那个。
- 怎么用这个方法论：不照旧例取旺，反过去抓那个落空的爻——因为答案的时间点是从它身上长出来的（出空之日）。
- 得出什么结论：财必得；先推次日辛丑冲动未土之日到手，又把应期改落在那条空爻出空之日。
- 实际结果如何：果然得了财，但到手的日子是辰土出空之日，不是先前推的辛丑日——反证当初选那条空爻是对的。

**其三｜三个子孙爻，独取落月破的那两个（c04，卷二《两现章》第三十二）**
- 遇到什么问题：亥月丙午日母亲问儿子何时脱厄，卦里三处挂着子孙标签，其中一处临日建却安静（看着最有力），另两处落月破（看着最没劲）。
- 怎么用这个方法论：不取临日建的那个，专取落月破的那一组——破是待时，应期就落在补齐这个破的年份上。
- 得出什么结论：许巳年脱厄，即实破之年。
- 实际结果如何：果于巳年脱厄。作者在案后补了一句，他敢断巳年还因为这家人此前两个人的卦也同指这一年。

**其四｜同一个"官鬼持世"，问官职与问流年所得截然相反（c05，卷二《增删〈黄金策千金赋〉》第三十四）**
- 遇到什么问题：求占者已经托人去办援例，却打着"问本年流年"的名义来；卦上代表自己那一爻挂的正是官鬼标签。
- 怎么用这个方法论：先把事类纠过来——问官职时这个标签代表官本身，落在自己身上是喜；问一年顺逆时它代表压着我的东西，落在自己身上是忌。事类一改，同一位置的符号方向随之翻转。
- 得出什么结论：援例业已成，申日文书实收俱到。
- 实际结果如何：果于申日文书与实收同到。作者附了一句：若真的照"问流年"把它当压身之物去断，相差就太远了。

## A2 — Future Trigger（何时被调用）

**语言信号（中英双写）：** 用神取什么 / 占某事看哪一爻 / 用神两现 / 用神不上卦 / 代占该怎么取 — `yong shen` / `which line` / `use god` / `multiple candidate lines` / `lacking use god`.

1. **用户直接问某个事类该看哪个爻。** 用户会说："占这件事我应该看哪一爻" / "问提拔是看世爻还是别的" / "which line is the yong shen for a job？"。这是本卡的主触发。
2. **卦里出现了两个以上同标签的爻。** 用户会说："我这一卦有两个财爻，算哪个" / "two wife-wealth lines, which one？"。触发多现的取舍规则。
3. **要找的那一类爻在卦里完全不上场。** 用户会说："卦里没有父母爻怎么办" / "can't find the line, use the hidden one？"。触发"先看月日、不行就再占一卦"，并明确禁止翻找补救手段。
4. **用户要替别人问。** 用户会说："我替我女儿占一下考试该看什么" / "问配偶升职该看哪一爻" / "asking about spouse's promotion, what line？"。先触发代占禁忌，再决定能不能继续。
5. **需要把现代事类翻译过来。** 用户会说："问融资该看哪一爻" / "面试、签证、签合同、动手术算哪一类" / "which line for funding / surgery / visa"。触发五元归类原则，要求说明是按哪一条推出来的。

**与相邻能力的区分：** 本卡只回答"**看哪一爻**"，不回答"旺不旺"（→ `sishen-wangshuai`）、"何时"（→ `yingqi-tuiduan`）、"要不要拆成几卦问"（→ `fenzhan-duozhan`）、"整体格局是不是一票否决"（→ `daxiang-geju`）。**用神没定下来之前，不谈吉凶**——落点选错，后面所有测算都是白算。上游还需要 `qigua-zhuanggua` 先把六亲标签排好、`zhanqian-zhunbei` 先把问句钉死。

## E — Execution（可执行步骤）

1. **把问目锁成一句话。** 只接受两种形态：是非题（"这件事成不成"）或时间题（"什么时候应"），并当场写下来。
   - 完成标准：这句话能被回答"是/否"或能落到一个时间点；若它同时含有"能否"和"何时"，本卡不接，先交给 `fenzhan-duozhan` 切分。
2. **把这件事归进五个类别之一。** 依次对照：它是否在遮护或承载我（→父母）、是否在约束或压着我（→官鬼）、是否与我同类而在分我之利（→兄弟）、是否为我所驱使或归我使用（→妻财）、是否属于克患解忧的那一类（→子孙）。
   - 完成标准：能说出"归 X，理由是它在我的处境里起 Y 的作用"。若是书上没有的新事类，必须明确交代是按上面哪一条推的，不许含糊说"大概是"。问生死、问疾病、问官非、问钱财时，同时标明"我今天问的是它的哪一面"（是"能否"还是"何时"）。
3. **在排好的卦单上找这个标签的爻。** 三种情形分别处理：
   - 只找到一处 → 直接定为落点。
   - 找到两处以上 → 不要自动挑最旺的那个；先问"哪一处能给我一个时间点"（落空者待出空、落破者待实破、发动者待其动足），把它定为落点，并**书面说明为什么舍掉另外那个**（舍它的理由必须是"待时/不动/无所应"，不能是"我看着顺眼"）。
   - 一处都找不到 → 先查当时的月建、日辰能不能充当；能就直接用并标明"以日月为用神"；**不能用则不得去翻伏神、互卦、化气那一套**，改为重新摇一卦，直到出现为止。
   - 完成标准：能完整说出"本卦主看第几爻（某在某），次看第几爻（某在某）"，以及每一处取舍的一句话理由。
4. **检查这次问话是谁的念头。** 若是别人托我来问，先停下来：按本卡的禁忌，这一步可能根本无从选取。
   - 完成标准：能确认"这一卦的念头出自当事人本人"；若确认不了，输出应当是一句"此卦无从取用神"，而不是硬挑一个爻出来。
5. **判停点。** 出现下列任一情形就停下，不许往下谈吉凶：①第 1 步的问目本身还含糊（既是"能否"又是"何时"，或者没写清是哪一种具体事项）；②第 2 步找不到可归的类别且说不出推理依据；③第 3 步遇到"一处都没有"而用户拒绝再占；④第 4 步发现念头不属于本人。停下的处置分别是——退回 `zhanqian-zhunbei` 重写问句、补问一件事的关键细节、说明本卦不可用并建议再占、如实说明代占不可取。

## B — Boundary（边界）

### 1. 不要用这个能力的场合（反场景）

- **要谈强弱、要下定论**：交给 `sishen-wangshuai`；本卡只交付"看哪一爻"，不交付"吉还是凶"。
- **要问什么时候应**：交给 `yingqi-tuiduan`；本卡只负责把能指示时间的那个爻挑出来。
- **要不要把一件事拆成几卦**：交给 `fenzhan-duozhan`；本卡的 E 第 1 步发现含糊时就是往这里退。
- **能不能由别人替我问**：那是 `zhanqian-zhunbei` 的提问规范；本卡只在其后果层面上处理"代占则无从取用神"。
- **纯事实查询**：贷款利率、合同条款、签证材料清单这类可查证的事实，应让其去核实，本卡不予受理。

### 2. 作者在书里警告过的失败模式

- **x05｜另立"卦身／身位／世身"来代表所占之人或事。** 作者逐条试过均不应验，自己的做法是"凡遇到所谓的身，一律按世爻处理"，并且明确把这一整套删掉。本卡只认六种标签加世应两套位置。
- **x08｜所寻之处不上卦时，硬去翻伏神、互卦、化气。** 作者的看法是：这几种补救手段的旺衰出处本身就难以把握，正确答案很简单——再摇一卦合参。
- **x15｜占父母寿元以阳爻作父、阴爻作母。** 作者直斥此论为非，正确做法是一律看父母爻的旺衰与生扶，并且祖父祖母与父母要分开占。
- **x19｜我事命人代占。** 代占者掺进了自己的念头，选出来的落点从根子上就是错的；本书的处理方式是拒绝选取，而不是勉强挑一个。
- **x22｜泛问而不指实。** 问的人是冲着"看看今年如何"来的，卦上却没有任何一处能对应一个具体事项，此时选爻必然落空，应先把问目切成具体的是非项。

### 3. 作者的局限（来自阶段 0 批判）

- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

### 4. 安全边界

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。

- `zhanqian-zhunbei`（占前立意与提问规范）——**依赖/前置**：问句不钉死，本卡的落点就会跟着摇摆（典型后果即案例其四）。
- `yingqi-tuiduan`（应期推断十二条）——**后继/对比**：本卡在多现时偏偏要挑那个能给出时间的爻，正是为了给它留出接口。

- `fenzhan-duozhan`（分占与多占）——**组合**：本卡判停时往它退；它也会反向要求本卡在多个卦上各自重新选一次落点。
