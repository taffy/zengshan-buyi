# 占此应彼 / 占远应近的重配对诊断

## R — Reading（原文）

> 「占此应彼，必须详察。大凡占出卦象，必须细为详查，卦有不应所问之事，而反应所未问之事，其故何也？神有舍小事而报大事，有舍小吉而报大凶，有舍此应彼，占我应他，占他应我，乃旦夕祸福将至，机之一动，卦必现，故曰：知机其神乎，此之谓也。」
> ——卷二 增删《黄金策千金赋》· 占此应彼

> 「占远应近，务必留心……卦之成者戏以远而报近事，或以近事而报远。」
> ——卷二 增删《黄金策千金赋》· 占远应近

## I — Interpretation（自述）

这是一个**兜底级的重配对工具**，处理的是"卦明显不在回答我问的那件事"这种情形。作者不承认这是失败，而是把它解释成一种机制：神会按重要性重排报事顺序。

**四种错位模式。** 作者的原话给出四种：舍小事而报大事、舍小吉而报大凶、占我应他、占他应我。机制解释是"旦夕祸福将至，机之一动，卦必现"——祸福越近越大，越抢先在卦里显现；另一处说得更白："人之至亲莫过于骨肉，人之得志莫过于利名，神不告已问之事者，以重大者而先告也。"

**还有一类是时间尺度的错位。** "占远应近，占近应远，占月应年，占日应时"——问本月的事，卦却报出寿元；问中秋的雨，卦却应在初九。作者给的解释是"两心相感"的强度问题：事在目前、心神迫切，卦就立应；事尚无几、或是戏问，两心不相摄，卦就茫然，于是拿远事报近事、拿近事报远事。

**三条整合判据（必须同时满足，才可改读为别的事）。** 这是本卡的核心，缺一不可：
1. 所问之用神**完全不在场**——不现，且伏神也不得用出；
2. 卦中动爻/变爻强烈指向某个爻，且该爻与所问之事**无关**——它有明显的生克冲合动作，指向另一个六亲或世应；
3. 该爻对应的事在**量级上更大**（配得上"舍小事而报大事""舍小吉而报大凶"）。

只满足一条或两条 → **不得改读**，那更可能是误读或取用不当，应回到原问或再占。

**本卡是最后一道转译，不是第一道。** 卦看着不对题，绝大多数时候是常规原因（用神取错、踩了某条被删的古法、问目含混）。排查顺序固定为：`qu-yongshen` → `pimiu-fanmoshi` → `fenzhan-duozhan` → **最后**才考虑本卡。

**认识论代价（务必理解后再用）。** 这个机制与"灵机变通""多占合参"一起，构成一套事后解释装置：卦不准时，永远可以归因于"神在报别的事"。这使全书规则体系原则上不可能被任何反例推翻。所以用它时，你是在**主动降低可证伪性**，必须限用：三条判据齐备、措辞带不确定性、并建议另占一卦验证。

## A1 — Past Application（书中案例）

**1. 巳月己未日占小厮之病（c21）**
- **问题**：主人来占家中仆役（小厮）的病，卦象却完全不显示仆役之病。
- **怎么用**：识别"占他而应我"——不看所问的小事用神，转而看卦中真正强烈发动的信号：世临卯木之官，化申金子孙回头克，这是问卦人自身的功名之灾。三条判据齐（小厮用神不在场 / 世爻动而化回头克指向问卦人自己 / 革职比仆人小病量大得多）。
- **结论**："此卦不应小厮病，而应今秋功名有碍。"
- **实际结果**：果于七月被论革职。作者当场向对方说明："我问小厮，如何应在功名？神之机常常如此，舍小事而报大凶。"

**2. 申月戊寅日自占身病（c22）**
- **问题**：占病者自称病重，但卦中世爻虽绝于寅日却当秋令旺相，反倒是妻财爻化回头克之象极为显眼。
- **怎么用**：先判世爻（绝于寅日但秋金旺相 → 自身无灾），再顺着卦中最凶的信号（亥水财爻化戌土回头克）追到"占我应他"——落到亲属身上。
- **结论**：自身"子孙持世，不药而愈"；但"防九十月妻财有危"。
- **实际结果**：不久病愈，九月妻死。

**3. 酉月甲辰日占本月月令（占近应远）**
- **问题**：问的是一个月之内的运气，卦却给出与月令无关的远期信号。
- **怎么用**：世爻午火动化亥水回头克，作者判断这不是月令层面的吉凶，而是寿元层面的大凶——属"占近而应远"。机制解释是"神不告已问之事者，以重大者而先告也"。
- **结论**：卦现的是寿元，不是本月月令。
- **实际结果**：其人辰年占卦，在午年子月而死。

**4. 酉月初五戊子日占中秋雨（占远应近 / 应期尺度错位）**
- **问题**：卦中辰土父母发动，按常法"当许中秋有雨"。
- **怎么用**：作者识别出卦所应的时间坐标不是中秋，而是发动之爻所值的近日——"殊不知应在初九辰日即雨"。随后于壬辰日再占"中秋晴否"、癸巳日又占，两卦一财动一子动、不见父鬼爻动。
- **结论**：初九辰日有雨；中秋夜转晴。
- **实际结果**：果于中秋夜"月明星稀"；而雨已先应在初九。**要点**：时间尺度的错位同样属于本卡，且作者的处置是**再占验证**，不是硬把卦拽回中秋那一天。

## A2 — Future Trigger（何时被调用）

1. **用户主动提出"这个卦好像说的不是我问的事"。**
   用户会说："我明明问的是工作，怎么卦里全是家里的象？""这卦是不是不准？"
   触发词：卦不准 / 好像说的不是我问的事 / 对不上题 / off-target reading / wrong question
   → **先走排查顺序**，不要直接改读。

2. **问 A 事，但卦里某个六亲强烈异常，且与 A 无关。**
   用户会说："我问我爸的病，但子孙爻动得很凶，这跟我爸有什么关系？"
   触发词：别的六亲 / 动得很凶 / 跟我的问题无关 / irrelevant line / unrelated moving line
   → 检查三条判据，尤其第 ② 条（有无强烈指向无关的爻）。

3. **问近事，却断出很远的意象。**
   用户会说："我就问这个月，怎么卦里像是在说好几年后的事？"
   触发词：占远应近 / 占近应远 / 时间对不上 / 占月应年 / time-scale mismatch
   → 属于本卡的第二类错位，处置同样是"另占一卦验证"。

4. **同一个卦，换个事类读反而说得通。**
   用户会说："如果把它当成问健康的，反而一切都对上了。"
   触发词：换个事类 / 换个读法 / 反倒说得通 / reinterpret / re-pair
   → 仍须先排除常规原因；判据不全就是误读。

**与相邻能力的区分（排查顺序，务必照此执行）：**
- 第一步 `qu-yongshen`：用神取对了吗？事类锁定了吗？（同一"官鬼持世"，占功名以官为官、占流年以官为鬼。）
- 第二步 `pimiu-fanmoshi`：是不是踩了某条被作者删掉的古法？
- 第三步 `fenzhan-duozhan`：卦是不是只是"恍惚"？那就再占一卦。
- 第四步 **本卡**：以上三步都排除了，才考虑改配对。
- 与 `daxiang-geju`：大象（卦变回头克）是**卦内**的层级关系，本卡是**卦与问目之间**的配比关系，不是一回事。
- **用户并未提出错位疑点时，不要主动启用本卡。**

## E — Execution（可执行步骤）

1. **先排除常规原因（三项任一命中即停）。**
   逐项检查：① 用神是否取错（转 `qu-yongshen`）；② 是否踩了 `pimiu-fanmoshi` 清单里的某条被删古法；③ 问目是否明确（主体 / 地点 / 时间尺度 / 是是非题还是程度题）。
   *完成标准*：三项都给出了明确的"是/否"结论。任一为"是" → **停止，转对应卡，不进入本卡**。

2. **逐条检视三条判据，并记录命中情况。**
   ① 所问之用神是否**完全不在场**（不现，且伏神也不得用出）？
   ② 卦中有无动爻/变爻强烈指向某个与所问之事**无关**的爻（有明确的生克冲合动作，指向另一六亲或世应）？
   ③ 该爻对应的事在**量级上是否更大**（配得上"舍小事而报大事""舍小吉而报大凶"）？
   *完成标准*：写出"①是/否 ②是/否 ③是/否"三行，并各附一句卦中依据。

3. **三条全中 → 输出"候选重配对"，并建议另占验证。**
   措辞必须带不确定性："此卦**可能**在报 X 事，而不是你所问的 Y 事。"禁止用肯定句下断语。同时建议就 X 事**另占一卦**验证。
   *完成标准*：输出一句话，其中含"可能""候选"一类限定词；并已明确建议另占。

4. **未三条全中 → 判定为误读或取用不当，回到原问。**
   按原问事类重新读卦；必要时转 `fenzhan-duozhan` 再占一卦。
   *完成标准*：输出明确的一句"证据不足，按原问读，建议再占"，并说明缺的是哪一条判据。

5. **收口。**
   *完成标准*：输出要么是一句带"可能"限定词的候选重配对（+另占建议），要么是明确的一句"证据不足，按原问读，建议再占"。**不允许出现第三种输出**（尤其不允许"卦不准"这种无信息量的结论）。

## B — Boundary

**1. 不要用这个能力的场合（反场景）**
- **它不是"卦不准"的挡箭牌。** 卦看着不对题时，首选排查顺序是 `qu-yongshen` → `pimiu-fanmoshi` → `fenzhan-duozhan`，本卡排在最后。
- **用户没提出错位疑点时不要主动启用。** 主动改读等于把"卦不准"常态化。
- 纯 factual 查询（"六冲是哪六组""卷三有多少章"）不该起卦，也不进入本卡。
- 若真正的问题只是卦象恍惚，请直接用 `fenzhan-duozhan` 再占，不要绕道本卡。

**2. 作者在书里警告过的失败模式**
- **x27 把"占此应彼"当作默认解释**：卦与所问不合就一句"神在报别的事"，反而掩盖真问题（用神取错、问目含混、踩了被删的古法）。作者的验案（小厮病应主人革职、自占身病应九月妻亡、占母病先现子女有灾）都是**在卦中另有极重大信号**时才改读，不是随手改读。
- 相邻的风险：`fenzhan-duozhan` 的 x20——卦已明现还再问，神转而报告未问之事。**"卦已明"与"卦在报别的事"是两种不同诊断**，不可混用：前者要停，后者才谈重配对。

**3. 作者的局限（来自阶段 0 批判，四条）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- **"占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。** 本卡正是这套机制的核心部件：卦不准时，永远可以归因于"神在报别的事"，所以对任何结果都能给出解释。使用它意味着**主动降低可证伪性**，因此必须限用（三条判据齐备 / 措辞带不确定性 / 建议另占验证）。这是全书批判部分的直接产物。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**4. 安全边界**

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。
>
> **本卡尤其危险的一点**：重配对会把卦象改读到"疾病""死亡""官非"这类重大事项上（书中的验案正是如此）。现代使用时，任何指向健康、法律、人身安全的改读都必须以"可能"措辞给出，并**明确引导至专业渠道**，不得作为预警依据。

## 相关能力

- `fenzhan-duozhan`（分占与多占）——**组合 + 上游排查项**。排查顺序里它排在本卡之前（先确认不是"卦只是恍惚"）；本卡提出候选重配对后，也要靠它"另占一卦"来验证。
- `qu-yongshen`（取用神）——**上游排查项**。排查第一步就是用神有没有取错、事类有没有锁定。
- `pimiu-fanmoshi`（辟谬与反模式清单）——**上游排查项**。排查第二步：是否踩了某条被作者删掉的古法。
- `daxiang-geju`（大象优先与格局判定）——**对比**。大象是卦内层级关系（卦变回头克不看用神衰旺），本卡是卦与问目之间的配比关系；不要拿大象凶来冒充"占此应彼"。
- `zhanqian-zhunbei`（占前立意与提问规范）——**依赖**。问目若没切成是非题，后续所有"错位"判断都不可靠。
