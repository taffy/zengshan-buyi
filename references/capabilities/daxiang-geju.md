# 大象优先与格局判定

## R — Reading（原文）

> 卷一 卦变生克墓绝章第二十四

卦变者：变生、变克、变墓、变绝、比和。予得验者，凡遇卦化克者，不论用神之衰旺皆以凶推。……又如午月丙寅日占主病，得离卦变坎卦，离火变坎水，回头来克，但因午月火旺，许之冬令必危。果卒于九月丁亥日。此皆不看用神之衰旺也。

> 卷一 六冲章第二十、六合章第十九

冲者散也，凡占凶事宜于冲散、占吉事而不宜，必兼用神而言，用神旺虽冲不破，用神失陷凶而又凶，六合卦变六冲卦者，用神旺者始吉终凶，图事难成，有始无终也。诸合皆以用神旺者为吉，独此六冲卦变六合得不看用神，竟以吉断。

## I — Interpretation（自述）

这张卡管的是**整卦的结构与优先级格局**，回答"这卦整体是什么性质"。它跑在逐爻加权之前，因为作者规定了一层明确的层级：**大象（卦变）> 用神衰旺 > 逐爻生克**。

**a) 大象压倒用神，但二者分工。** 当变卦回头来克本卦（巽木变乾金、震木变乾金、离火变坎水这类），作者明文"不论用神之衰旺皆以凶推"。但要注意这不是"用神白看了"：大象定的是**性质**（凶），用神旺衰定的是**应期与程度**（何时凶、凶多重）。午月占主病得离变坎，夏天火当令，看上去无碍，作者却许之"冬令必危"——因为火旺只是一时之气，卦体被连根拔起才是终局。所以"旺卦断凶"并不自相矛盾，只是两者的时间坐标不同。

**b) 六冲是双刃，不能一见就定性。** 冲＝散，所以凶事（官非、盗贼、忧疑、久病）喜冲散，吉事（功名、财、婚姻、合伙）忌冲散。但作者立刻加了一句限定：**必须兼看用神**——用神旺则"虽冲不破"，用神失陷才"凶而又凶"。疾病一门最锋利：同一个逢冲逢空，近病断"不药而愈"，久病断"妙药难医"。相关地，日辰冲静爻：旺相者是**暗动**（有力，福祸来而不知），休囚者是**日破**（无用）；月建冲爻则是**月破**。

**c) 六合和六冲一样要看动静与方向。** 静爻逢合叫"合起"（有用，即使休囚也有旺相之意），动爻逢合叫"合绊"（反而动不了）。更要紧的是两条方向相反的格局：**六合化六冲**＝先合后离、始荣终悴、得而复失；**六冲化六合**＝散而复聚、失而复得、先难后易——后者是全书罕见的"可以不看用神、竟以吉断"的特批格局。三合局则要查世爻位置：**世爻在局内、或局生世爻方吉，局克世爻为凶**；局中有一爻空破者待填实，有一爻入墓者待冲开。

**d) 进神退神是过程不是状态。** 亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌为进；反向为退。作者用"进神四法、退神四法"推翻了古法"动逢月破、化空破谓之不进不退"：旺相化旺是乘势而进，休囚化休囚是待时而进，有一而衰待旺相之日进，有一而空破待填实之日进；退神四法同构。所以化进不等于立刻成，化退也不等于立刻败，都要落到"待某日/某时"。

**e) 反吟伏吟读作反复。** 反吟（卦变回头冲克）＝"成而败、败而成"，去而复来、来而去；伏吟＝呻吟忧郁、欲动而不能。**反伏本身不是吉凶，是曲线**：用神旺相不变冲克，虽反复终究事成；用神化回头冲克，才是卦变大凶。伏吟者，旺相则冲开之年伸志，休囚则冲开之年不吉。

**f) 元原则：神兆机于动。** 动爻是信息的载体，动必有因。由此推出一组"动爻免疫"条款：动不为空、动不终破、旺相有气者冲之不散。这也是本卡区别于"静卦全靠旺衰"的关键——**先看动爻变出什么，再看静结构**。

**g) 一组次要但常用的修饰项**：贪生贪合（忌神贪生贪合则"刑冲克害皆忘"，不来克我）；太过者损之斯成 / 用爻重叠喜墓库以收藏（用神太多不是无用，是待损之日或墓库之日成之更稳）；克处逢生（此处受克、他处得生）；制中弱主难以维持；**回头克几乎一票否决**（世爻或用神化鬼、化回头克，即使旺相、即使逢三合，仍须以凶推）。

## A1 — Past Application（书中案例）

**1. 卯月癸未日占终身财福，世与日月三合看似大吉，实为世爻变鬼化回头克**（卷三 终身财福章第三十七，泽火革变风火家人）
- **遇到什么问题**：来人问一生的财与福。卦的外卦与日、月合成三合，世爻又动，是典型的"吉卦"外象，按常规可直断亨通富足。
- **怎么用这个方法论**：不被外象带走，先扫大象与动变：世爻亥水发动，化出的却是官鬼未土——既是**变鬼**，又是**回头克**；同时上爻未土又动来克。三合局虽成，但它是"被冲开就散"的时间性结构。
- **得出什么结论**：目前虽无妨，但今年五月冲开其合、或酉月冲开卯木时须防不测。
- **实际结果如何**：果于巳月生恶疮，卒于酉月——两个推定的应期窗口先后都应了。

**2. 未月丁巳日占已悔婚还可成否，六冲变六合，作者不看用神直断必成**（卷一 六合章第十九，离卦变火山旅）
- **遇到什么问题**：婚事已经反悔，来人问还能不能成。卦体是六冲（离为八纯之一），按"冲者散也"的常法应当断散。
- **怎么用这个方法论**：作者启用他自验的例外条款——诸合皆以用神旺者为吉，**唯独"六冲卦变六合"这一格局可以不看用神、竟以吉断**，读作"散而复聚、离而必合"。
- **得出什么结论**：此婚一定还成。
- **实际结果如何**：果于次年三月仍成婚。

**3. 卯月壬申日占随官府上任，内卦反伏＋世化回头冲克，作者劝"不去为上"**（卷一 反伏章第二十五，水地比变水风井）
- **遇到什么问题**：要不要跟随一位官府去上任。世爻临官鬼又值月建，看上去"随去必成"，是好事。
- **怎么用这个方法论**：先读格局曲线——内卦反伏，主"事有反复、去而复来"；再读动变——世爻卯木官鬼**绝于申日**，又动而化酉金，**回头冲克**。作者明言：反伏本身只是反复，怕的是用神化回头冲克，那就是卦变大凶之象。
- **得出什么结论**：此行不吉，**不去者为上**。
- **实际结果如何**：后来官府直接得缺、驻地近贼营，此人辞而不去；官府走后，他又因他故随去；至七月城破，与官府一同被害。

## A2 — Future Trigger（何时被调用）

1. **用户问"这卦整体什么性质""大象怎么看"，而不是问某一爻。**
   用户会说："这卦整体是吉是凶" / "大象怎么看" / "worst thing in this hexagram" / "daxiang" / "overall pattern"。
   *区分*：问整体结构 → 本卡；问逐爻加权与旺衰净值 → `sishen-wangshuai`。

2. **卦出现卦变，且疑似回头克或回头冲（巽变乾、离变坎、震变兑、艮坤化震巽等）。**
   用户会说："卦变回头克是不是就完了" / "我这是巽之乾，怎么办" / "the changed hexagram attacks the original"。
   *区分*：本卡定性质（凶），随后回 `sishen-wangshuai` 定程度，再交 `yingqi-tuiduan` 定"何时"。

3. **卦是六冲、六合，或出现六合化冲 / 六冲化六合的转换。**
   用户会说："是不是六冲" / "六合变六冲是不是先好后坏" / "六冲变六合是不是就没事了" / "liuchong / liuhe conversion"。
   *区分*：六冲化六合是可跳过用神直断吉的特批格局（本卡）；仅"六冲"本身必须兼看用神，结论可能完全相反。

4. **动爻化进化退，或出现内外卦反伏吟。**
   用户会说："这是化进还是化退" / "是不是反吟" / "伏吟是不是很凶" / "jin shen / tui shen / fan fu yin"。
   *区分*：本卡给"时间曲线"（先吉后凶 / 先凶后吉 / 反复），不给具体日期。

5. **遇到三合局，用户问是否需要世爻入局、或问这个局吉不吉。**
   用户会说："三合局成了吗" / "我不在局里怎么办" / "局克世爻是不是凶" / "sanhe ju / three-harmony bureau"。
   *区分*：局之吉凶看"世在局内 / 局生世 / 局克世"，这是本卡；局成之期（待填实、待冲开）属 `yingqi-tuiduan`。

## E — Execution（可执行步骤）

**1. 先看有无变卦，检查大象（回头生 / 回头克 / 变墓 / 变绝 / 比和）。**
- 动作：写出"本卦 X 宫 → 变卦 Y 宫"，比较二者五行：变卦生本卦＝化生（吉），变卦克本卦＝**化回头克（凶）**，比和＝中性。同时单独检查**世爻或用神动而化出之爻**是否回头克本爻。
- 完成标准：输出一句"大象＝化生 / 化回头克 / 比和"。
- **判停点**：若命中**卦变回头克** → 记录"大象：凶（不论用神衰旺）"，第 2–4 步只作修饰项采集，不再改判吉凶，直接跳到第 5 步。

**2. 查六冲 / 六合及其相互转换。**
- 动作：依次判定——① 本卦是否属十个六冲卦之一（八纯卦＋天雷无妄、雷天大壮）；② 本卦/变卦是否六合；③ 是否**六合化六冲**（先合后离、始荣终悴）；④ 是否**六冲化六合**（散而复聚、先难后易）。
- 完成标准：四项各写一个"是/否"。
- **判停点**：若命中**六冲化六合** → 这是压倒性格局，可**不看用神竟以吉断**，跳过第 3–4 步。
- 硬约束：仅"六冲"本身不得直接定性，必须"兼用神而言"（用神旺则虽冲不破，用神失陷则凶而又凶）；近病逢冲逢空即愈、久病逢冲逢空即凶，须先问清病程。

**3. 处理动爻：看它变出什么。**
- 动作：对每个动爻判定——化进神还是化退神（亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌为进，反向为退）；是否化鬼、化回头生、化回头克；有无**贪生贪合**（忌神被别爻引开而不来克我）；有无**太过 / 用爻重叠**（待损之日或墓库收藏之日成）。
- 完成标准：每个动爻一行，写明"化进/化退/回头生/回头克/化鬼/贪合忘克"中的适用项。
- 硬约束：进退用四法判，不得用古法"动逢月破、化空破谓之不进不退"作废。

**4. 查三合局与反伏吟。**
- 动作：① 找申子辰、巳酉丑、寅午戌、亥卯未三合，判定成局与否（少一字者为"虚一待用"，待后时月日填之）；② 查世爻是否在局内、局生世还是局克世；③ 查内卦/外卦是否反伏。
- 完成标准：三合写出"成局/虚一待用 + 世在局内/局生世/局克世"；反伏写出"内/外/内外 + 用神是否化回头冲克"。
- 完成标准补充：若反伏命中，须写明曲线（成而败、败而成 / 呻吟忧郁），并标注用神旺相与否。

**5. 合成输出。**
- 动作：按"大象定性质，格局定曲线，旺衰定振幅"输出一句断语。
- 完成标准：能说出——"**大象＝X（性质：吉/凶/中性）；其余格局＝Y、Z（修饰：先吉后凶 / 反复 / 待填实 / 贪合忘克……）**"。
- 完成标准补充：若第 1 步命中回头克，断语中必须保留"不论用神衰旺皆以凶推"这一性质判定，不得因用神旺而翻成吉。

**6. 交回加权层。**
- 动作：把"大象＝X、格局＝Y、Z"连同"哪个动爻最吃重"一起交给 `sishen-wangshuai` 做四处清算与程度判定；要日期则再交 `yingqi-tuiduan`。
- 完成标准：本卡不输出具体日/月/年；也不输出"吉/凶"的最终数值，只输出性质与曲线。

## B — Boundary（边界）

**1. 不要用这个能力的场合（反场景）**
- 用户只问"这爻旺不旺""元神忌神谁有力" → 那是逐爻加权，转 `sishen-wangshuai`；本卡不逐爻算净值。
- 用户问"什么时候""哪天/哪月/哪年" → 本卡**不定应期**，转 `yingqi-tuiduan`；本卡只给时间曲线（先吉后凶之类），不给坐标。
- 卦象与所问之事明显对不上 → 转 `zhanci-yingbi`，不要靠格局硬套成所问之事。
- 卦中乱动、内外竞发、吉凶不定 → 转 `fenzhan-duozhan` 再占合参。
- 想用六神、星煞直接断生死 → 见 `pimiu-fanmoshi`：它们"不能独操祸福之权"，只作附和。
- **纯 factual 查询不该起卦**：天气查气象预报、疾病就医、法律咨询律师、财务找持牌顾问；这类问题直接查事实，不要进入断卦流程。

**2. 作者在书里警告过的失败模式**
- **x28 见六冲即断"凶事可散 / 吉事必败"**：作者明写"必兼用神而言"。他还举了一卦：六冲官事本宜冲散，但该卦六冲变冲且世爻化鬼，结果"一家俱受刑"，并未因冲而解。
- **x26 见世爻旺 / 三合成局即断吉，忽略化出回头克**：终身财福一卦，世与日月三合本是大吉外象，实为世爻变鬼化回头克，其人果卒。回头克是全书最重凶兆之一，即使旺相、即使逢三合，仍须以凶推。
- **x23 见月破即断无用**：月破是"待时"，动者出月不破、实破之日不破、逢合之日不破。
- **x24 见旬空即断全空**：除真空外一律按出空、冲空、填实之日而应；作者自述初学卜时正是栽在这里。
- **x11 信古法"动逢月破、化空破谓之不进不退"**：作者连举数例反证，改用进退四法；化空者待出空、化破者待实破之日月而应。

**3. 作者的局限（阶段 0 批判，四条例行）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。他删掉"不验"的古法，凭的同样只是个人经验判断，没有统计支撑。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪；卦不准时永远可以归因于"神在报别的事"。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹、随官府上任、城破被害），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**4. 安全边界**

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。
