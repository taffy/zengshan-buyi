# 分占与多占（不确定性处理）

## R — Reading（原文）

> 「教学者凡遇卦之恍惚，心若未明，多占无碍，倘卦中已明现，不可再渎。」
> ——《增删卜易》序（野鹤老人自述）

> 「诸书占身命，谓妻财子禄一卦，能包寿夭穷通，六爻兼断。殊不知父子财官兄弟，各有相忌相伤……岂世之有父母者，皆无子嗣之人也？……觉子曰余今得其法，乃分占之法也……占终身子嗣及帮元俱宜分占。」
> ——卷三 身命章第三十六

## I — Interpretation（自述）

这套方法处理的是"卦已经出来了，但信息不够、或者信息互相打架"的情形。它有两个方向，最容易被混为一谈：

**分占（横向拆问题）。** 一个卦只答一个问题。理由不是"态度要虔诚"，而是逻辑上做不到——六个用神之间存在固定的互克关系（父母克子孙、兄弟克妻财、子孙克官鬼），所以同一爻在一卦之内既是吉兆又是凶兆。作者的反证很直白：如果"父母旺相"算吉，那么"父旺伤子"就必须同时算凶，等于说天下有父母的人都没有儿子、"世之贫人寒士，皆失偶之人"。因此身命、终身财福、终身功名、夫妻偕老、子嗣寿元必须各占一卦。分占还有两种非事类的用法：**拆时间尺度**（久远之财与目下之财分开断）、**拆问目**（同一卦，问"何时来"与问"是否平安"可以结论相反）。

**多占（纵向重新采一次样）。** 卦象恍惚时，次日洁诚再占一卦，两卦合参而断。作者引《易经》"三人占听二人之言"来反驳"不敢再三渎"这条禁忌，并自述"余生平以来稍得其奥者，全赖多占之力也"。操作上不拘早晚、不必焚香，"事之缓者，迟迟再占，事急者歇歇又占"。

**用神不现时不取伏神。** 古法的补救链是伏神→互卦→化气，作者认为这条链越走越牵强（伏神自身的衰旺空破就难以把握，互卦更是"非惟牵强且错误颇多"），直接换成一句"再占两卦用神必现"。

**停止条件是硬边界。** 卦已经明白显现，就不可再占。判据是"卦明不明"，不是"我满不满意"。作者自己踩过这个坑：明知辰日得财，次日就同一件事再问一次，结果神不再回答已问的事，改报申日另一起破财。

**多占不是投票。** 它绝不是"连摇几次、取多数"——那属于"占到满意为止"，正是作者点名的"再三渎"。正确的合参是看几卦是否指向**同一用神的同一状态变化**；若始终对不上，说明问题出在问目，而不是样本不够。

## A1 — Past Application（书中案例）

**1. 辰月乙卯日占求财（c13，卷一 旬空章第二十六）**
- **问题**：首卦妻财丑土持世却遇旬空，本该断难求；但三月丑土有气，古法又有"有气不为空"一说，两说冲突，不敢径断。
- **怎么用**：不硬凑，直接"命之再占"。后卦得子水财爻空伏于五爻未土之下——伏而又空、空而被克。两卦合参。
- **结论**："财无气矣，不必劳心。"
- **实际结果**：后果全无。作者把这一条写成了旬空章的总纲："后得多占之法，凡遇旬空，命之再占，卦吉者许之出旬而不空，卦得凶者许之空矣。"

**2. 占府尊能否复职，连占三卦（c14，卷二 增删《黄金策千金赋》）**
- **问题**：首卦子孙持世、官临应爻，断"万万难于复职"，对方不服，认为今日不诚，请他明早诚意再卜。次日再占，卦与前卦雷同（世爻破而入墓、官星两现皆空破），仍不能决。
- **怎么用**：作者说"再占一卦不妨"，占第三卦，得五爻官鬼化进神。三卦合参：前两卦的"官破入墓"＝本地爵位已失，第三卦的"官化进神"＝另有再任之官。
- **结论**：此地爵位已失，速速援例，可再任西方。
- **实际结果**：不准复职；后援刑例，果于巳年补陕西庆阳府知府。**要点**：前两卦雷同并不等于信息重复，一直占到出现分化为止。

**3. 占雨而父爻旬空，不敢定日（c15，卷二 天时章第三十五）**
- **问题**：卯木父母动而值旬空，只能在"己酉日"与"卯日"两个候选日之间摇摆，无法定夺。
- **怎么用**："不难，再占一卦。"再占到离卦不动（与前卦相同），又占到艮之谦，三卦合参，以各卦动爻所值之日排出连续三天的天气序列。
- **结论**：甲寅日阴云，乙卯日必雨，辰日又晴。
- **实际结果**：果于寅日云、卯日大雨、辰日大晴。**要点**：多占不只用来决吉凶，也用来消除**应期歧义**。

**4. 序中自述的反面教材（c16）**
- **问题**：一日占求财，旺财持世，作者自己已经明知辰日得财，却次日就同一件事再占一卦，得"申金兄动而不得"，与首卦矛盾。
- **怎么用**：事后复盘才明白——卦已明则神不再回答已问之事，转而报告未问之事。
- **结论**：首卦辰日得财属实；再占所得的"申金兄动"对应的是另一件事。
- **实际结果**：辰日果得财，至申日因他事而破财。这条被作者写进序里，作为"已明则不可再渎"的实证。

## A2 — Future Trigger（何时被调用）

1. **卦出来了，但拿不准，想再占一次。**
   用户会说："这一卦我看不懂，能不能再摇一卦？""我刚才那卦是不是不算？"
   触发词：能不能再占 / 再摇一卦 / 重新起卦 / re-divination / cast again
   → 走多占分支，先判"卦明不明"。

2. **已经连占好几卦，结论不一致。**
   用户会说："我摇了三次，一次吉一次凶，到底听哪个？""是不是多摇几次取多数？"
   触发词：结论不一样 / 三卦不一致 / 取多数 / conflicting readings
   → 走多占分支，并**当场否定"取多数"这个想法**。

3. **一个卦想问好几件事 / 一个人想问好几个人。**
   用户会说："这一卦能同时看我的事业和婚姻吗？""能不能顺便看看我爸妈？"
   触发词：一卦多问 / 兼断 / 一次问完 / split reading / multiple questions one hexagram
   → 走分占分支，拆成一事一卦的是非题。

4. **用神不上卦，问要不要找伏神。**
   用户会说："卦里没有我要的爻，是不是要找伏神/互卦？"
   触发词：伏神 / 互卦 / 化气 / 用神不现 / hidden spirit / fu-shen
   → 走"不取伏神→再占"分支。

5. **同一件事，想问长期也想问眼前。**
   用户会说："这笔钱到底能不能赚？""今年能不能成？"
   触发词：长期 vs 眼前 / 久远之财 / 目下 / long-term / short-term
   → 走分占的时间尺度拆法（久远与目下分开断）。

**与相邻能力的区分：**
- 本卡处理的是**卦出来之后**信息不足怎么办（横向拆问 / 纵向再占）；`zhanqian-zhunbei` 是**摇卦之前**的提问规范（一念一事、亲占、指其事而占）。二者互补：分占失败往往是因为上游问题没切干净。
- `qu-yongshen` 如果判定"用神不现"，会触发本卡的"不取伏神→再占"。
- `zhanci-yingbi` 处理的是另一种错位（卦在说别的事）。连占三卦仍不能统一时，正确动作是**回到提问层重做**，而不是继续摇卦，也不是急着改读成别的事。

## E — Execution（可执行步骤）

1. **先判断不确定性属于哪一种，再选分支。**
   - ① 一卦塞了多个诉求（多个人 / 多件事 / 多个时间尺度）→ 转 step 2（分占）。
   - ② 单一诉求，但卦象含糊、多处冲突、或应期有两个候选 → 转 step 3（多占）。
   - ③ 用神根本不上卦 → **不取伏神、不取互卦、不取化气**，直接转 step 3（多占）。
   *完成标准*：能明确说出"我这是 ① / ② / ③"，并说出选它的理由；说不出就先回到 `zhanqian-zhunbei` 重写问题。

2. **分占（横向）：把诉求拆成一事一卦的是非题。**
   逐个拆：身命 / 终身财福 / 终身功名 / 夫妻偕老 / 子嗣寿元各一卦；"何时来"与"是否平安"各一卦；"久远之财"与"目下之财"各一卦。每一卦问句必须是"是/否"或"甲还是乙"。
   *完成标准*：写出的每个卦各自只有一个待答问题；任何一个卦仍含两个判定对象（人或事），就继续拆。

3. **多占（纵向）：换个时间，再占一卦。**
   次早洁诚再占（事缓者迟迟再占，事急者歇歇又占；不拘早晚，不必焚香）。**同一刻连占两次是不允许的**，必须隔到下一次起念。
   *完成标准*：拿到第二卦，且两卦的月建日辰都已记录清楚。

4. **判停点（关键，先于一切）：第一卦是否已经"明现"？**
   若用神显豁、大象清楚、答案已经摆在卦里 → **立即停止，不得再占**。只有当"卦有恍惚、心若未明"时才继续。
   *完成标准*：能回答"我再来一次，是因为卦没说明白，还是因为这个结果我不想要？"——答出前者才继续，答出后者即为"再三渎"，立即停止摇卦。

5. **上限与归谬：连占三卦仍不能统一，就停止摇卦。**
   此时不再起第四卦，而是回到 `zhanqian-zhunbei` 重做提问——多半是问目本身不清（主体不明、地点不明、时间尺度不明、是是非题还是程度题没分清）。
   *完成标准*：能写出一句经过改写的是非题，并说明原问句错在哪。

6. **合参收口。**
   *完成标准*：能说出"本卦主用神及所指之人/事"，且前后两卦指向**同一用神的同一状态变化**（不是简单的"两吉一凶算吉"）。说不出统一指向 → 回 step 5，不要硬断。

## B — Boundary

**1. 不要用这个能力的场合（反场景）**
- 卦象已经明白显现时，不许用本卡去"再确认一次"——那是渎占。
- 用户只是想查 factual 信息（"《增删卜易》有多少章""六冲是哪六组"），不该起卦，也不进入本卡。
- 下列情况请转对应卡片：卦在说别的事 → `zhanci-yingbi`；不确定哪条古诀可信 → `pimiu-fanmoshi`；问题还笼统没切成是非题 → `zhanqian-zhunbei`。

**2. 作者在书里警告过的失败模式**
- **x20 卦已明现而再三渎占**：明知辰日得财仍次日再问，结果"神不告已问之事，而又以我未占之事告我"（报了申日破财）。
- **x21 卦象恍惚却硬断**：作者自述初学卜时"凡遇旬空，无法而断"，作全空则常应填实、作不空又确有到底全空；单卦无从分辨，"无故自空，如入深渊大凶。实则旺财生世，腰缠万贯之征。许之去耶？阻之勿去耶？"
- **x08 用神不现硬寻伏神、互卦、化气**：李我平指出"古法用伏神虽有验，然伏神之衰旺休囚刑冲克害月破旬空亦有难于把握者"，互卦更是"非惟牵强且错误颇多"；作者的主张只有一句——"再占两卦用神必现"。
- **x13 一卦兼断身命父子财官**：五类六亲各有相忌相伤，一卦兼断必然自相矛盾。

**3. 作者的局限（来自阶段 0 批判，四条）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。"多占"本身也有同源风险：作者用"卦已明则不可再渎、卦恍惚则可再占"来调和，但"卦是否明"是主观判断，等于给"一直占到满意为止"留了口子（他自己也承认占功名占过七次）。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**4. 安全边界**

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。

## 相关能力

- `zhanqian-zhunbei`（占前立意与提问规范）——**组合 + 上游依赖**。本卡 step 5 的归谬终点就是回到它重做提问；分占能否成立取决于上游问题是否已切成是非题。
- `qu-yongshen`（取用神）——**触发关系**。它判定"用神不现"时，转给本卡的"不取伏神→再占"分支。
- `zhanci-yingbi`（占此应彼 / 占远应近的重配对诊断）——**对比**。同属不确定性处理，但本卡是"重采样"，它那张是"重配对"；本卡用尽（连占三卦仍不决）才考虑它，且它必须限用。
- `pimiu-fanmoshi`（辟谬与反模式清单）——**对比**。本卡的"不取伏神"是它第 7 条辟谬的直接产物；它也记录"一卦兼断"（第 12 条）应改为分占。
- `yingqi-tuiduan`（应期推断十二条）——**组合**。多占不仅决吉凶，也用于消除应期歧义（c15）；应期推不出来时，作者给的兜底也是"再占一卦，不可妄断"。
