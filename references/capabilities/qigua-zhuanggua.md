# 起卦与装卦六步

> capability_id: `cap.zengshanbuyi.qigua-zhuanggua`
> 来源：f01 / f02 / f05(side) / glossary 装卦·浑天甲子·六亲·世应·动爻 + x10

## R — Reading（原文）

**段一｜卷一《卦象图第二》（摇卦记爻、四象定性）**

> 一个背，两个字，称作“单”．画乍“ ′ ”为少阳。
> 两个背，一个字，称作“拆”，画作“ ″ ”为少阴。
> 三个背，没有字，称阼“重”，画作“O”为老阳，是变爻。
> 三个字，没有背，称作“交”，画作“X”为老阴，是变爻。
> 共摇六次，第一次为初爻，画在卦的最下面，依次上升……如遇有X、O，再画出变卦来。

**段二｜卷一《卦象图第二》（定卦名次序）＋ 卷一《八宫图第三》（泽天夬变天风姤装卦示范）**

> 因为点卦时，由下至上，排卦名时，是由上往下排，此卦上卦为坎，为水，下卦为离，为火，所以此卦卦名为水火既济卦。
> ……按六亲者姤卦之丑土、戌土原是父母，今俱写兄弟何也?六亲须照前卦而按前卦泽天夬土为兄弟，所以变卦之丑、戌二土也写兄弟。

## I — Interpretation（自述）

这六个步骤干的事，是把三枚铜钱的结果翻译成一张可以读的清单。整条链路纯属机械装配，任何一步都不许夹带吉凶判断。六步各自的产出物如下。

**第一步，摇卦记爻。** 三枚铜钱合扣在手心，脑子只许想着那一件事，摇六次，从下往上一次一次把结果记下来。产出：六个阴阳符号，自初爻到六爻排成一竖列。

**第二步，给每一爻定性。** 一个背面属少阳、两个背面属少阴、三个背面属老阳（记作 O）、三个字面属老阴（记作 X）；带圈和带叉的那几个就是会变化的爻。产出：六个爻各自的性质，并标出动爻在哪几位。

**第三步，定卦名。** 底下三爻是内卦、上头三爻是外卦，**念名字时先念上卦、后念下卦**——坎在上、离在下要念成水火既济，倒过来念就成了另一个卦。产出：一个确定的卦名。

**第四步，配地支五行。** 按"浑天甲子"的规则，八纯卦每一爻的地支与五行是固定的（例如乾卦在内是子水寅木辰土、在外是午火申金戌土），或者直接到"八宫全图"里把这一卦的六个爻照抄下来。产出：六个爻都带上了地支和五行属性。

**第五步，安六亲。** 以这一卦所属那一宫的五行当作"我"，按五种关系贴标签：生我者为父母、我生者为子孙、克我者为官鬼、我克者为妻财、与我同属性者为兄弟。产出：六个爻各自的角色名。

**第六步，定世应与排动变。** 每宫八个卦各有固定的世爻位置，从世爻隔两位就是应爻；凡是记 O 或 X 的爻都要翻面（阳翻成阴、阴翻成阳），翻出来的那一卦就是变卦。产出：一张同时标明世应、六亲、地支五行、动变四层信息的完整卦单。

第六步里藏着一条最容易出错的硬规定：**变卦那一侧的角色标签不许按变卦自己的宫来贴，必须回头照原来那一卦所属之宫推算**。所以夬卦变出的姤卦，那两个土爻若站在姤卦本宫里本来该叫父母，可它们此刻是写在夬卦旁边，就得照夬卦的规则写成兄弟。

另外，作者给完全不懂五行生克的人留了一条降级路线：只学会点卦，到全图里照抄世应五行六亲，然后**只盯住代表自己那一爻、看它上面挂着哪个角色**，四件大事就能粗判——问前程见官鬼在这一爻就说能成，见子孙就说还得等；问钱财见妻财就说必得，见兄弟就说难求；问防灾见子孙就说无忧，见官鬼就说要提防；问病看是不是六冲卦。作者给这套降级法的理由是：神灵知道你不懂，就会递给你显而易见的卦；你一旦懂了五行，卦反倒会把转折藏起来。**两条路互斥**——只要稍懂生克之理，就不许再走降级路线，必须补念浑天甲子与六亲歌、学动变、再去看用神元神忌神。降级路线只能给粗判，不能断细事，也不能推应期。

## A1 — Past Application（书中案例）

**其一｜泽天夬变天风姤的完整装卦示范（卷一《八宫图第三》）**
- 遇到什么问题：新手点出六个爻之后，既不知道怎么装出世应五行六亲，也不知道动爻翻出来的那一卦该怎么排。
- 怎么用这个方法论：六步从头走一遍——先定上下卦名（上三爻是兑为泽、下三爻是乾为天，按上卦在前念作泽天夬）；到全图里照抄这一卦的世应五行六亲；再看动爻，上卦第六爻由"交"翻面、兑变成乾，下卦初爻由"重"翻面、乾变成巽，天在上、风在下，变卦就是天风姤；最后把姤卦那两个对应爻写回本卦动爻旁边。
- 得出什么结论：得到一张夬变姤的完整卦单，并且额外加一条批注——姤卦那两个土爻在本宫里原该是父母，但因为它们现在写在夬卦旁边，仍须照夬卦的规则写成兄弟。
- 实际结果如何：作者把这一张当作标准作业的样子摆在卷一，明确交代"余卦仿此"；此后全书上百个卦例都沿用同一套四层装排，未见例外。

**其二｜乾为天卦例：同一张卦单上逐一演示各处生克来源（卷一《八宫图第三》后附入门示范）**
- 遇到什么问题：点出乾为天之后，初学者不知道一个爻到底要怎么被衡量强弱。
- 怎么用这个方法论：作者拿同一张卦单，对六个对象挨个示范——自占吉凶的那一个爻、父母的两个爻、兄弟、妻财、官鬼、子孙，每个对象都数四处来源：月建、日辰、卦中其他发动之爻、以及它自己变出来的那个爻。
- 得出什么结论：一个爻的强弱不是凭感觉，而是这四处来源逐项过一遍再加总。作者定了裁决次序：四处俱来生合则诸事全吉；三处生一处克仍以吉断；两生两克要比较旺衰；三克一生时，若那唯一生扶者旺相尚可算"克处逢解"，若它自己休囚，那是"有生之名无生之实"，与四处俱克同断大凶。
- 实际结果如何：这一段被作者明确写成入门纲领（"以上所论诸事……写此以为纲领，引尔入门也"），后续所有旺衰测算都建立在这四处来源的框架之上。

**其三｜"我不知五行焉能断卦"——降级路径的一问一答（卷一《八宫图第三》后问答）**
- 遇到什么问题：作者把八宫全图送给一位在外游宦的朋友，朋友说：我不懂五行，这东西对我没用。
- 怎么用这个方法论：作者让他先学点卦，点出来是什么卦就翻到全图里找这一卦，照样抄出世应五行六亲，不必背卦诀、也不必懂生克，只盯住代表自己那一爻站的是哪个角色；并且交代万一所需角色这一卦里压根没出现，那就再占一卦。
- 得出什么结论：四件大事可以只看这一个变量粗判；作者还配了更简易的形式——摇卦前先跟神灵约定"若能成，请给我官鬼站在这个爻上；若无望，请给我子孙站在上面"，把输出压到一眼能读的范围。
- 实际结果如何：作者当场划了硬边界并写进书里：这条路只对**完全不知五行生克**的人开放，稍懂者"神必现隐微之卦"，必须回头走上面那条六步加旺衰的完整路线，且作者明说"不可以此为法"。

## A2 — Future Trigger（何时被调用）

**语言信号（中英双写）：** 装卦 / 排六爻 / 安六亲 / 世应在哪 / 变卦怎么排 / 纳甲 / 摇卦 / 浑天甲子 — `hexagram setup` / `na jia` / `six relatives` / `shi and ying` / `changing line` / `hun tian jia zi`.

1. **用户直接给出六次摇掷的背字结果，要求排出卦来。** 用户会说："我摇的是背背字、字字背……帮我排出来" / "I got three heads, help me set up the hexagram"。本卡完整启用六步。
2. **用户的装卦结果与书上或本卡对不上。** 用户会说："我装的六亲怎么跟你不一样" / "这一爻到底该配哪个地支" / "my six relatives don't match"。回到第四、第五步逐项核对。
3. **不知道世爻应爻在哪。** 用户会说："这一卦世在哪、应在哪" / "which line is the shi"。只回答第六步中的位置规则，不做任何吉凶解释。
4. **不知道变卦那一侧怎么算。** 用户会说："变出来的卦要不要重新安一遍六亲" / "how do I label the transformed hexagram"。触发"变卦的标签照本卦之宫推算"这条硬规定。
5. **问"不懂五行能不能断卦"。** 用户会说："我完全没学过五行也能占吗" / "can I read a hexagram without knowing wu xing"。触发双层路径的切换判断。

**与相邻能力的区分：** 本卡**只产出卦单，不做吉凶判断**——输出的是位置与属性数据，不含任何好坏暗示。用户接着问"这卦好不好"→ `sishen-wangshuai` 或 `daxiang-geju`；问"该看哪一爻"→ `qu-yongshen`；问"要不要再摇一卦"→ `fenzhan-duozhan`；提问本身还没成型（一卦想问多件事、要人代占）→ `zhanqian-zhunbei`，那是本卡的前置。

## E — Execution（可执行步骤）

1. **摇卦记爻。** 三枚铜钱合扣手心，只念着那一个问题，摇满六次，每次的背字情况当场记下；第一次的记在最底下的初爻，逐次往上，第六次记在最上爻。
   - 完成标准：手上有一列自下而上、共六行的背字记录（例如"一背、两背、三背、三字、三背、两背"），且每次记录都不缺。
2. **给每一爻定性。** 一背＝少阳，两背＝少阴，三背＝老阳记 O，三字＝老阴记 X。
   - 完成标准：六行全都换成符号（阳画单横、阴画断横），并且所有 O 与 X 都被圈出——这就是动爻名单，动爻数量可能是 0 到 6 个。
3. **定卦名。** 下三爻取为一个经卦作内卦，上三爻取为一个经卦作外卦，**先念上卦后念下卦**。
   - 完成标准：得到一个卦名，并能反过来说明"上卦是 X、下卦是 Y，念作 X 上 Y 下"。上下卦念反的一律作废重念。
4. **纳甲装配地支五行。** 按浑天甲子的固定搭配逐爻添上地支与五行；拿不准就直接翻"八宫全图"把这一卦六爻照抄。
   - 完成标准：六个爻各自的旁边都写上了地支与五行，且内外卦所配的那一组地支与所用规则一致（可直接跟全图逐字比对，能对上即通过）。
5. **安六亲。** 先定这一卦属哪一宫、该宫五行属什么，再以它当"我"，按生我／我生／克我／我克／同我五种关系给六爻贴标签。
   - 完成标准：六个爻全部贴上了标签，没有一个留空；贴完后检查一遍数量关系——同一卦里五种标签的出现次数组合应与全图该卦完全相同。
6. **定世应、排动变。** 按该卦在本宫的次序定位世爻，从世爻隔两位定为应爻；把每个 O 翻成阴、每个 X 翻成阳，翻完的那一卦就是变卦；变卦的标签**照本卦所属之宫推算**，不得就地按变卦自己的宫改算。
   - 完成标准：卦单上同时出现四个要素——世爻位置、应爻位置、变卦卦名、变爻旁的标签；且每个变爻旁写有"本爻：某在某 → 变爻：某在某（照本卦之宫算）"。
7. **判停点（在第 6 步末尾执行）。** 六个爻里若一个 O/X 都没有，这就是安静之卦，**不要为了凑出变爻去翻找别的东西**——没有变卦可排，带着这张卦单直接进入旺衰判断即可。反之，只要出现了 O 或 X，必须把变卦六爻一并排出并在本卦旁注明，不允许只排本卦就交付。

## B — Boundary（边界）

### 1. 不要用这个能力的场合（反场景）

- **用户想讨论吉凶、成败、应期**：交给 `sishen-wangshuai`（旺衰）与 `yingqi-tuiduan`（应期）；本卡不产出任何结论性判断。
- **用户问"该看哪一爻"或"我这件事落在哪一爻"**：交给 `qu-yongshen`；本卡只负责把六个爻都摆出来。
- **用户纠结要不要再摇一卦、要不要把一个问题拆成几卦**：交给 `fenzhan-duozhan`。
- **提问本身还不合格**（一卦想装两三件事、要替别人摇、问得太笼统）：退回 `zhanqian-zhunbei`，本卡不接受污染过的输入。
- **纯事实查询**：用户问的是可查证的事实（政策条文、药物说明、车次时刻），应当让他去核实，本卡不予受理，也不代为起卦。

### 2. 作者在书里警告过的失败模式

- **x10｜舍用神而执"独发／独静"断祸福。** 作者承认只有一根爻发动（或只有一根爻安静）的情况他本人也遇到过应验的，但明确指出那是在"验事应之后"用来合参的印证，**不能事前拿来断**。本卡的相应纪律是：把动爻标出来就算完成任务，不许因为出现了独发、六冲、六合之类的形态就顺手给出吉凶结论。
- **越界行为：排完卦单顺手断一句。** 这是本卡最高频的失控点——从业者排到一半忍不住加一句"这卦看着不错"。本卡必须输出**中性数据**：静爻／动爻／变卦／世应／六亲／地支五行都只是位置与属性信息，不含任何吉凶暗示，也不含任何倾向性措辞。

### 3. 作者的局限（来自阶段 0 批判）

- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

### 4. 安全边界

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。

## 相关能力

- `zhanqian-zhunbei`（占前立意与提问规范）——**依赖/前置**：它为第 1 步提供那一句唯一的问话；没有它，整条六步链路的输入就是脏的。
- `qu-yongshen`（取用神）——**依赖/后继**：本卡排出的六亲清单是它选爻的唯一素材；`qu-yongshen` 反过来又决定了本卡哪一步的产出会被真正使用。
- `sishen-wangshuai`（四神模型与四类作用力旺衰）——**后继**：本卡交付卦单之后，旺衰测算接手；它有本卡所没有的"四处来源"裁决规则。
- `daxiang-geju`（大象优先与格局判定）——**后继/对比**：六冲、回头克一类格局信息同样由本卡排出的动变数据产生，但只有它有权下结论。
- `pimiu-fanmoshi`（辟谬与反模式清单）——**约束**：它通过 x10 等条目给本卡划出"排完不得顺手断卦"的红线，并清理卦身、身位一类本不属于六步的附加操作。
