# 边界、拒绝与判停（安全红线）

> capability_id: `cap.zengshanbuyi.anquan-bianjie`
> 来源：卷三《趋避章》第四十（"圣人作易，原令人趋吉避凶……若使吉不可趋，凶不可避，圣人作之何益"）
> ＋ 阶段 0 批判（作者局限四条）＋ 现代使用边界

## R — Reading（原文）

**段一｜卷三《趋避章》第四十**

> 圣人作易，原令人趋吉避凶，若使吉不可趋，凶不可避，圣人作之何益？世人卜之何用？……
> 若占得死于水者，莫近河旁，死于刑者，不可违条犯法，未有不化凶而为吉。

**段二｜卷三《趋避章》第四十（趋避的落点）**

> 最忌官鬼持世。凡占防患克世者，皆不为吉，独鬼爻克世更凶……避患于生世之方，趋吉于福神之地。

## I — Interpretation（自述）

这张卡不是断卦流程的一步，而是**压在整条流程之上的闸门与判停表**。它回答两类问题：

**第一类：这个问题根本不该用六爻来答。** 医疗诊断与用药、法律后果、金融投资决策、人身安全与刑事风险评估——这四类无论卦象如何，都不能据卦下结论。理由是认识论的，不是道德劝诫：本书的方法是清代的符号推演系统，它对这四类问题没有任何校准过的预测力；而使用者在焦虑中会把"卦说没事"当成不就医、不签约、不止损的理由，这个代价是真实的、单向的。作者自己在趋避章里给出的也是**行动建议**（"莫近河旁""不可违条犯法"），而不是"躺平等应验"——换句话说，本书的正统用法是**把卦当成趋避的提示，而不是结果的判决**。

**第二类：这个卦现在不能继续往下断。** 判停是本书方法自带的组成部分，作者在多处明设了停止条件：卦已明现就不可再渎；连占多卦仍不决要回到提问层；问目含糊就先不打卦；"占此应彼"未同时满足三条判据就判误读。判停不是失败，是方法的一部分——继续硬断才是失败。

**排查顺序（tie-break 规则）**：当同一请求同时命中多张卡时，按下列顺序取第一张，不要并行开跑：
1. `anquan-bianjie`（本卡）——先看是否踩红线、是否需要判停；
2. `zhanqian-zhunbei`——问目是否成立（一念一事、亲占、指实）；
3. `qu-yongshen`——用神是否取对；
4. `daxiang-geju`——有无压倒性格局（大象回头克、六冲化六合）；
5. `sishen-wangshuai`——逐爻加权；
6. `yingqi-tuiduan`——应期；
7. `pimiu-fanmoshi`——自查有没有踩被删的古法（随时可插入）；
8. `fenzhan-duozhan`——不决则再占 / 分占；
9. `zhanci-yingbi`——**最后**才考虑改读为别的事。

**全流程请求的加载顺序**：用户要求"从头走一遍"时，按 `zhanqian-zhunbei → qigua-zhuanggua → qu-yongshen → daxiang-geju → sishen-wangshuai → yingqi-tuiduan` 逐步推进，**每完成一步先向用户确认再进下一步**，不要一次性输出整条流水线的结论。

## A1 — Past Application（书中案例）

1. **汉口索债渡江**（趋避章第四十）：此人欲渡江索债，占得"本日日辰动化进神克世，因世爻落空，辰时出空被日月动爻之克，必有危亡之祸"。野鹤不是断一句"凶"了事，而是**留他吃早饭拖过辰时**；此人饭后再去江边，正撞上四只大船覆没、尸满长江。→ 遇到什么：一个明确的凶兆且时间可指；怎么用：**用行动避过**（拖时间），而不是加算吉凶；结论：此祸可避；实际结果：人活下来了，野鹤归功于"兄之德行"而非自己算得准。

2. **寅月丁卯日占流年**（趋避章第四十）：断"六七月木衰墓之时，防土木之厄"，并明指**宜往东方**避。此人初七又得凶梦，初八往东行二十八里，地震房塌、人口被伤，**独他得免**。→ 遇到什么：时间可定、方向可定的凶；怎么用：给出**时间与方位**两个可操作维度；结论：往东可避；实际结果：应验，独免。

3. **作者删规则时的自我判停**（随鬼入墓章第三十、星煞章第三十三）：作者不是"想到就删"，而是"**存留验，不验又试，试之不验，而再试之，一而十，十而百，全不验者始尽删之**"。→ 遇到什么：一条流传已久的古诀；怎么用：**反复试到百例不验才删**，单次不验不足以否定；结论：删；实际结果：作者用这条判据删掉了随鬼入墓、卦身身位、星煞独断等一批规则。**这条判据本身也适用于本 skill 的每一条规则**。

## A2 — Future Trigger（何时被调用）

**场景**：
1. 用户拿医疗（体检结果、要不要手术、用什么药）、法律（会不会败诉、判几年）、金融（要不要买/卖、什么时候涨）、人身安全（会不会出事、要不要出行避险）来要求断卦或给结论日期。
2. 用户要求代占（替不在场的人摇卦），或要求替他人起念。
3. 用户一次抛出多个诉求想一卦问完。
4. 卦已明现但用户还想再占；或已经连占多卦结论仍冲突。
5. 用户怀疑"卦在说别的事"，但证据不足三条判据。
6. 用户要求"从头到尾走一遍完整流程"。

**用户会说什么（语言信号）**：
「帮我起一卦看这个结节要不要手术」/「占一下这场官司能不能赢」/「卦说我该不该加仓」/「能不能替我朋友占一卦」/「我一次问完好几件事吧」/「我再占一卦确认一下」/「连占三卦都不一样，是不是在说别的事」/「从摇卦到断吉凶帮我走一遍」
`medical divination` / `should I have surgery` / `legal outcome` / `investment timing` / `proxy casting` / `multiple questions` / `read again` / `full pipeline`

**与相邻能力的区分**：
- 本卡是**闸门**，排在排查顺序第 1 位；其余 8 张卡都在它之后。
- `zhanqian-zhunbei` 处理**问目的形式规范**（一念一事、亲占、指实），本卡处理**问题的性质是否可答**与**是否该停**；代占两条卡都会碰到，但**先过本卡的红线判定**。
- `fenzhan-duozhan` 处理"卦不决怎么办"，本卡处理"这个问题不该继续"——前者答案是再占，后者答案是停止并引导。
- 本卡**不给任何吉凶结论，也不给应期**。

## E — Execution（可执行步骤）

1. **红线扫描**（完成标准：四类各答一个是/否）
   - 是否涉及医疗诊断、用药、手术或预后？
   - 是否涉及法律后果、罪责、判决？
   - 是否涉及金融投资、买卖、行情点位？
   - 是否涉及人身安全、刑事风险、出行避险？
   → 任一为**是**，进入第 2 步；全否，进入第 3 步。

2. **拒绝并引导**（完成标准：输出必须包含三句话）
   - 说明：六爻属传统数术与民俗知识体系，不是科学预测方法，本书案例是作者自选的应验记录且无对照组；
   - 明确：**不给**这四类问题的结论、吉凶或应期；
   - 引导：给出对应的专业渠道（医生 / 律师 / 持牌投资顾问 / 警方或应急部门）。
   → **判停**：到此结束，不得进入取用神或旺衰环节。

3. **形式检查**（完成标准：三问各答一个是/否）
   - 是否为他人代占？（是 → 拒绝代占，说明"我事不可命人"，建议由本人动念自占）
   - 是否一卦多问？（是 → 要求拆成一事一卦，列出拆分后的各个是非题）
   - 卦是否已明现而用户仍要再占？（是 → 说明"卦已明现不可再渎"，停止）
   → 任一为**是**，判停并给出修正后的做法；全否，进入第 4 步。

4. **不决检查**：若用户已连占多卦仍结论冲突 → 判停，回到 `zhanqian-zhunbei` 重做提问（多半是问目不清），**不得**继续摇卦，也**不得**直接改读为别的事（`zhanci-yingbi` 排在最后）。

5. **全流程请求的编排**（完成标准：能说出下一步是哪张卡，且已向用户确认上一步的结果）
   `zhanqian-zhunbei → qigua-zhuanggua → qu-yongshen → daxiang-geju → sishen-wangshuai → yingqi-tuiduan`，逐步推进、逐步确认。

6. **收尾必答的第四句话**：任何断语之后都要补一句认识论限定——本书方法无对照组、无失败率统计，且"占此应彼/灵机变通"使其原则上不可证伪；结论带不确定性，仅供参考。

## B — Boundary（边界）

**不要用这个能力的场合**
- 用户只是询问本书的知识（作者、成书年代、术语释义、某章讲了什么）→ `overview` / `glossary`，不需要过红线扫描。
- 用户要的是客观信息（天气、行情、交通、医学检查数值）→ 直接查资料，不起卦。
- 与占卜完全无关的任务（写代码、算账、翻译）→ 不触发。

**作者在书里警告过的失败模式**
- x19（我事命人代占，取用神必错）；x18（心怀两三事而一卦求之，卦必乱应）；x20（卦已明现而再三渎占，神反告未问之事）；x21（卦象恍惚却硬断，不用多占）。
- 趋避章的反面教训：把卦当成"结果已注定"而**不作为**——作者的原意恰恰相反，他留人吃饭、指人往东，是把卦转成行动。

**作者的局限（来自阶段 0 批判）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**安全边界（本卡的核心，必须逐字执行）**
> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。
> 补充：若用户表现出**现实危机信号**（自伤倾向、被侵害、急性重症），停止一切占卜环节，直接引导至急救/报警/心理危机干预渠道。

## 相关能力

- `zhanqian-zhunbei`（组合）：本卡判"能不能问"，它判"该怎么问"，两者串联使用。
- `fenzhan-duozhan`（对比）：不决时本卡说"停"，它说"再占/分占"——先看本卡。
- `zhanci-yingbi`（依赖）：改读为别的事排在本卡与 `qu-yongshen`、`pimiu-fanmoshi`、`fenzhan-duozhan` 之后，是最后手段。
- `pimiu-fanmoshi`（组合）：本卡第 3 步的形式检查常需回查辟谬清单确认判据。
