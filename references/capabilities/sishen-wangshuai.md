# 四神模型与四类作用力旺衰

## R — Reading（原文）

> 卷一 八宫图第三后「今余先点一卦，教尔学看用神及五行生克旺衰之理」纲领段（乾为天卦例）

以上四处若得全来生合用神者，诸占全吉。倘有三处相生一处相克，也以吉断。若有两处克两处生者，须看旺衰。生用神之神旺相者则以吉断，克用神之神旺相者可以凶推。尚遇三处相克一处相生，若得相生之爻旺相者也可断为克处逢凶中得解。若值休囚者有生之名无生之实，与四处俱来克者同断，诸占大凶。

> 卷一 用神元神忌神仇神章第九、元神忌神衰旺章第十

用神，即前各类之用神也。元神，生用神之神即为元神。忌神克用神之爻也。仇神者克元神而生忌神也。……以上论元神、忌神之有力、无力者，亦要用神有气，倘若用神无根谓之元神有力亦难生，忌神无力何足喜。……其如亥水月冲日克，值月破而被克，虽有生扶生之不起，如树无根，寒谷不回春也。

## I — Interpretation（自述）

这张卡解决的是全书最核心的一个问题：**一卦六爻里，到底该拿哪一爻当"我这件事"，又有谁在影响它，影响加起来算吉还是算凶。**

先把六个爻压缩成四个角色。所占之事对应的那一爻叫**用神**——它是唯一的计分对象，其余五爻都不直接计分。生用神的那一爻叫**元神**（给它供能的），克用神的那一爻叫**忌神**（威胁它的），克元神同时又生忌神的那一爻叫**仇神**——仇神是双重坏蛋：掐断补给线，还顺手资敌。所以吉凶不是"看六爻"，而是"看用神 + 三股外部力量的净值"。

第二个要点是**只有四处能作用于用神**。不要满卦找关系，能对它施加生、克、冲、合的只有：① 月建（当月的地支）；② 日辰（当日的地支）；③ 卦中其他发动的爻；④ 用神自己发动后变出的那个爻（回头生/克/冲/合）。静而不动的爻（除非旺相被日冲成"暗动"）基本只是背景。这四处里，**月建和日辰层级最高**：它们能生克任何爻，包括动爻、变爻、伏爻；反过来卦里任何一爻都伤不到日月——拿卦中一爻去"克掉"日辰来解凶，是错的。

第三个要点是**合成算法**，它是可数数的，不是靠感觉：四处全来生合 → 全吉；三生一克 → 仍算吉；两生两克 → 转为比较双方的旺衰，生方旺相就断吉，克方旺相就断凶；三克一生 → 关键只看那一处"生"旺不旺相，旺相就是"克处逢生、凶中得解"，**若那一处生扶本身休囚，那就是"有生之名、无生之实"，与四处全克同等看待，大凶**。这一步的核心洞察是：**数量不决定胜负，力度决定胜负**——四条克 + 一条无力的生，仍然等于大凶。

第四个要点是优先级的反转，也是本书最反直觉的一条：**用神自身的根，优先于一切外援**。如果用神自己休囚无气、被月破又被日克（"无根"），那么元神再旺、接续相生的链条再漂亮，也"生之不起"——作者的原话是像一棵没有根的树，寒冬的山谷不会因此回春。同理，忌神无力也不值得高兴：赢面在无形的那一头。所以顺序永远是"先看用神有没有根 → 再看元神忌神有没有力"，不能倒过来。

第五个要点是**旺衰是时间的函数，不是静态标签**。月建的加持只在当月有效，"当时旺相无伤，过时有害"：眼前极旺的卦完全可以断为将来凶，因为衰者遇时令会转旺（物穷则变），旺极者遇对冲时令会崩（器满则倾）。因此每一句旺衰断语都必须附带时效说明（月内 / 出月 / 到某时令），否则无法解释"旺卦断凶"。四项真正生效的时间状态只有长生、帝旺、墓、绝，其余八个长生位作者自称不验。

最后是**空与破都是"待时"而不是"终局"**。旺不为空、动不为空、有日建动爻生扶者不为空；只有"真空"（春土、夏金、秋木、三冬火）才是真的空到底。月破同理：发动的爻不终破，出月、实破之日、逢合之日就不破；只有不动又无生助的才是真破到底。

## A1 — Past Application（书中案例）

**1. 巳月乙未日自占病，接续相生也救不回"无根"的用神**（卷一 元神忌神衰旺章第十，泽风大过变火风鼎）
- **遇到什么问题**：野鹤自己生病，卦中未土忌神发动克世爻亥水，但酉金元神也发动，忌神未土转而生酉金、酉金再生亥水，形成"接续相生"——按常理已是标准的化凶为吉格局，看上去可以放心。
- **怎么用这个方法论**：不停在"关系"这一层，往上追一层权重：先看用神亥水自己有没有根。结果是月冲（巳月冲亥）、日克（未土克亥水），值月破又被克，属于"无根"。再套四处清算：四处之中对用神有利的只有元神这一条，且这一条也无力回天。
- **得出什么结论**：虽有生扶，生之不起，断凶——"用神无根，元神有力亦难生"。
- **实际结果如何**：果卒于癸卯日；卯日正是冲去酉金元神之日，应期与断语逻辑自洽。

**2. 辰月戊申日占父近病，三重父母爻择旺者，再逐处清算**（卷一 用神元神忌神仇神章第九，乾为天变风天小畜）
- **遇到什么问题**：来人问父亲的近病何时好。卦里辰、戌、未三重父母爻都有，先得决定"哪一爻才是我父亲"；而且卦是六冲，古诀说"近病逢冲即愈"，但病人病势很重，对不上。
- **怎么用这个方法论**：第一步定用神——三重父母爻中，辰土临月建为最旺，取辰土为用神。第二步四处清算：申日冲动寅木成暗动，寅木克辰土（这是一克）；卦中午火官鬼虽发动，但它化出未土、午未相合，合住了就不生辰土（这一处"生"实际失效）。所以辰土单受一克、不得生扶。
- **得出什么结论**：病体现在沉重，须待丑日冲去未土，午火脱离合绊、无合方能生辰土，那时病退。
- **实际结果如何**：果于丑日起床。

**3. 午月丁未日占弟被讼，两处可相敌、第三处一加就崩**（卷一 月将章第十六，泽水困变雷风恒）
- **遇到什么问题**：弟弟被人告发，问吉凶。用神酉金兄爻，午月克它，未日生它——一生一克，看上去可以相互抵消。
- **怎么用这个方法论**：作者补上第三处清算：卦中又动出一个午火来克酉金，而且这个午火正是月建入卦，"月建作忌神，为祸不浅"，即"最怕他爻增克制"。同时用神酉金化退神（酉化申），力量在向未来递减。再叠加时间尺度：今年辰年太岁与酉相合，暂时无妨；退到申年就无路了。
- **得出什么结论**：大凶之象，眼下无碍，申年难逃。
- **实际结果如何**：果于当年下狱，至申年而重刑。

## A2 — Future Trigger（何时被调用）

1. **用户已经装好一张完整卦单（有月建、日辰、六亲、世应、动变），问"这卦吉还是凶""这事成不成"。**
   用户会说："帮我看看这卦怎么样" / "这个卦是吉是凶" / "这卦到底旺还是衰" / "read this hexagram for me" / "is it auspicious"。
   *区分*：如果卦还没装出来，先转 `qigua-zhuanggua`；如果用神还没定，先转 `qu-yongshen`。

2. **卦里多爻生克混杂，看不出谁占上风。**
   用户会说："有的爻生它有的爻克它，听谁的" / "元神忌神都有，怎么算" / "谁能生克谁" / "multiple yao help and harm it, who wins"。
   *区分*：这是本卡的正主场；若混杂到四条规则互相打架、连旺衰也比不出高下，那是"卦恍惚"，交给 `fenzhan-duozhan` 再占。

3. **直接问旺衰术语或对某个单条旺衰标志有疑问。**
   用户会说："这卦旺不旺" / "用神无根" / "月破是不是就没用了" / "旬空是不是就空了" / "wang shuai" / "four forces" / "does yuepo make the yao useless" / "is xunkong really empty"。
   *区分*：问的是某一爻的权重 → 本卡；问的是整卦结构与压倒性格局（回头克、六冲、反伏）→ `daxiang-geju`。

4. **现代问题已转译并用神已定，需要定性。**
   用户会说："这个项目能不能成，我已经起卦了" / "这个 offer 该不该接" / "这笔款能不能到账"（用神取官鬼/妻财已定）/ "I cast for the startup question, now what"。
   *区分*：本卡只出"吉/凶 + 程度"，**不出日期**；要日期转 `yingqi-tuiduan`。

5. **有人拿一条"生扶"来求安慰，需要检验这条生扶是否真的算数。**
   用户会说："有元神动来生它，是不是就没事了" / "忌神被制住了应该无妨吧" / "the yuanshen moves to help, so I'm safe?"。
   *区分*：这正是"根先于援"的触发场景，本卡处理；若涉及的是作者对某条古法的辟谬判断，可并查 `pimiu-fanmoshi`。

## E — Execution（可执行步骤）

**1. 确认用神已定。**
- 动作：说出"所问之事 = 六亲 X + 地支 Y + 在第 N 爻"，并确认它是动爻还是静爻、是持世还是在他位。
- 完成标准：能一字不差地指出卦单上的**唯一一个**爻作为用神；若用神两现/三现，已按"择旺者、择动者、或按应期反取空破者"定下一个。
- **判停点**：说不出来 → 停止本卡，转 `qu-yongshen`。

**2. 在卦单上标出元神、忌神、仇神。**
- 动作：对除用神外的每一爻标注"生用神→元神 / 克用神→忌神 / 克元神且生忌神→仇神 / 无关→背景"。
- 完成标准：六个爻每个都有且只有一个角色标签；仇神若存在，已单独圈出（它同时做两件坏事）。

**3. 逐一处清算，输出一张四行表。**
- 动作：按下表逐行填写，每行只允许填"生 / 克 / 冲 / 合 / 无作用"之一，并注明该处自身旺相还是休囚：

| 作用力来源 | 对用神的作用 | 该处自身旺相/休囚 |
|---|---|---|
| ① 月建（月将） | | |
| ② 日辰 | | |
| ③ 卦中其他动爻 | | |
| ④ 用神自变之爻（回头生/克/冲/合） | | |

- 完成标准：四行全填满，没有一行留空或写"看情况"。
- 硬约束：日月单向——任何爻（含变爻、伏爻）都不能反伤日月；若你的推演里有"某爻克掉了日辰"，该行判错，重算。

**4. 按合成规则裁决吉凶。**
- 动作：数出四行里"生/合"几条、"克/冲"几条，然后按以下对照表落判：
  - 四处全来生合 → **诸占全吉**；
  - 三生一克 → **仍以吉断**；
  - 两生两克 → **比旺衰**：生用神之神旺相则吉，克用神之神旺相则凶；
  - 三克一生 → 看那一处"生"旺不旺相：旺相则"克处逢凶中得解"（仍凶但可解）；**若值休囚，"有生之名无生之实"，与四处俱克同断，诸占大凶**；
  - 四处俱克 → **大凶**。
- 完成标准：能输出一句完整断语："四处之中 X 生 Y 克，按第 Z 条 = 吉/凶"。

**5. 判停点（命中任一即停止加权，不再往下算）。**
- 5a. 用神属**真空**（春土、夏金、秋木、三冬火）→ 直接判凶，不必再看任何生扶。
- 5b. 用神**休囚无气又被克制**（无根）→ 直接判凶，元神再有力也不救；同时提示"根先于援"。
- 5c. 卦中出现**卦变回头克、六冲/六合转换、反伏**等大象格局 → 停止本卡，转交 `daxiang-geju`（大象先定性质，再回到本卡定程度）。
- 完成标准：三个条件逐条检查过一遍，并写明"命中/未命中"。

**6. 元神效能点数（有力五条 / 无力六条）——只有用神有根才需要跑这一步。**
- **元神能生用神者五**：① 元神旺相，或临日月，或得日月动爻生扶；② 元神动化回头生、或化进神；③ 元神长生、帝旺于日辰；④ 元神与忌神同动（忌神反来生元神）；⑤ 元神旺动而临空、化空（动不为空，出空之日有用）。
- **元神不能生用神者六**：① 元神休囚不动，或虽动而休囚又被伤克；② 元神休囚又逢旬空、月破；③ 元神休囚而动化退神；④ 元神衰而又绝；⑤ 元神入三墓；⑥ 元神休囚动而化绝、化克、化破、化散。
- 完成标准：给元神在两组清单里各打一个勾（最多各一个），并写出"有力 / 虽有如无"的结论。

**7. 忌神效能点数（有力五条 / 无力七条）——同样以用神有根为前提。**
- **忌神能克用神者五**：① 忌神旺相，或遇日月动爻生扶，或临日月；② 忌神动化回头生、化进神；③ 忌神旺动临空、化空；④ 忌神长生、帝旺于日辰；⑤ 忌神与仇神同动。
- **忌神不能克用神者七**：① 忌神休囚不动，或动而休囚被日月动爻所克；② 忌神静而临空破；③ 忌神入三墓；④ 忌神衰动化退神；⑤ 忌神衰而又绝；⑥ 忌神动化绝、化破、化克、化散；⑦ 忌神与元神同动。
- 完成标准：给忌神打勾并写出"如斧戟之忌神（大凶）/ 无力忌神（化凶为吉）"。
- 注意：入墓、化退在两边方向一致——元神墓/退则失效，忌神墓/退也失效，同一形态永远指向"这股作用力暂时不作数"。

**8. 给断语加时效条款。**
- 动作：判旺的写明"月内 / 出月如何"；判衰的写明"到某月令或太岁转旺"；旺极者写明"器满则倾，遇对冲时令须防"。
- 完成标准：断语末尾有一句明确的时间限定，不是一句孤立的"吉"或"凶"。

## B — Boundary（边界）

**1. 不要用这个能力的场合（反场景）**
- 用神还没定 → 转 `qu-yongshen`；卦还没装出来（缺月建/日辰/动变）→ 转 `qigua-zhuanggua`。
- 卦里出现卦变回头克、六冲/六合互化、反伏吟、三合局 → 这些是**压倒性格局**，先转 `daxiang-geju`，本卡只在其后做加权与程度。
- 用户问的是"什么时候"（何时成、何日到、哪一年） → 本卡**不给日期**，转 `yingqi-tuiduan`；本卡只回答"吉不吉、有多吉/多凶"。
- 四处清算互相矛盾、连旺衰也比不出高下（卦恍惚） → 不要加权硬凑，转 `fenzhan-duozhan` 再占。
- 卦象与所问之事明显对不上 → 转 `zhanci-yingbi`，不要靠旺衰硬套。
- **纯 factual 查询不该起卦**：天气看气象预报、疾病看医生、法律问题看律师、财务看持牌顾问；这类问题直接查事实，不要进入断卦流程。

**2. 作者在书里警告过的失败模式**
- **x25 用神无根却指望元神有力来救**：见到"忌神生元神、元神生用神"的接续相生就断化凶为吉，是最典型的错；用神月破日克无根时，这条链不成立（作者自占病一卦即卒）。
- **x23 见用神月破即断"到底无用"**：月破是待时，不是终局；动者出月不破、实破之日不破、逢合之日不破，只有不动又无日辰动爻生助才是真破。
- **x24 见旬空即断"到底全空"**：作者自述初学卜时在此长期失手；标准是先判真空/假空，除真空外一律按出空、冲空、填实之日而应。
- **x01 / x02 执"随鬼入墓"断生死而不看旺衰**：古法把日墓、动墓、化墓、身墓、命墓一律当死兆；作者改为只有"世爻休囚被克而又入墓"才是真凶，旺相者非真，墓神被冲破亦非真。同类错误还有"世临破鬼，祸患潜消"——鬼临月破只是目下不发，实破之年月仍应灾。

**3. 作者的局限（阶段 0 批判，四条例行）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。他删掉"不验"的古法，凭的同样只是个人经验判断，没有统计支撑。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪；作者自己也说"神报吉凶之月日不可照样而书符，全在人之变通"，规则可被事后无限微调。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译，否则取用神就会错。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**4. 安全边界**
