# 占前立意与提问规范

> capability_id: `cap.zengshanbuyi.zhanqian-zhunbei`
> 来源：f17 / p14 / p15 / p26 / x18 / x19 / x22 / c16 / c17 / c19

## R — Reading（原文）

**段一｜卷二《增删〈黄金策千金赋〉》第三十四（「占勿二念」「我事不可命人」二条）**

> 占勿二念，早晚何妨。一念之诚，可格天地。一篮之用，可享鬼神。若怀两三事而占者，念既不专心，何能一念多心？即是不诚！故曰：遇事即占，不认早晚，慎勿两念，二念不验
> 我事不可命人。我有心事，不可叫他人代我去占，我之一念，他又一念，事二念也！

**段二｜卷二《千金赋》第三十四（「他事由他动念」条）＋ 卷三《功名到何品级章》第六十六（指占之法）**

> 他事由他动念，慎勿提他。他之心事，未动念而占，我提醒他，叫他占，乃我之念也。
> 余得其法者，指占之法也。我能公侯否？我能将相否？我能一品否？……以教人指其事而占者，无不验也，何必谆谆执古法而猜耶？

## I — Interpretation（自述）

这套规矩管的区间是"还没摇第一枚铜钱"之前那段路。它把提问题当成一道必须验收的工序，而不是随便问一句就能开摇。核心骨架有五条。

第一条，一次只允许有一个念头。心里同时盘着两三件事就去摇，作者认为卦不会按你摇卦的先后顺序来报，很可能前卦应了后事、后卦跑去应前事，于是两个答案全被张冠李戴。所以多件事就要拆成多个问题、分多次占。

第二条，自己的事必须自己起念亲占。让别人替你摇，就掺进了别人的念头，等于两股心思并行，后面选哪一爻当落点都选不准。

第三条，别人的事要由他自己动那个念头。凡是你在旁边提醒、撺掇他去占的，卦响应的是你的心思。作者给的破法很具体：先把事情跟他说清楚，然后明确告诉他此时先别占，等他把这事忘一阵、忽然自己想起来再占——这样起出来的才算他自己的念。

第四条，问目要落到可以判定的具体事项上。不要泛泛地问"我这辈子功名如何""今年流年怎样""往哪边做生意赚钱"，而要切成一项一项的是非指向：援例这件事到底成不成、官能不能到某一品、某一地的某种货能不能做。同一个爻的吉凶会跟着问目翻转——官鬼落在代表自己那一爻上，问官爵是吉，问一年顺逆就是凶，差别全在问的是哪件事。

第五条补充一条硬性前置：正式起卦之前，先把当时的年月日辰写下来、按六神章把六神排好，再动手摇（见卷一《八宫图第三》）。

一句话概括：这阶段唯一的产物，是一个能被回答"是/否"或"某月某日"的、并且确实有一个人真心牵挂在上面的单句问话。

## A1 — Past Application（书中案例）

**其一｜明知辰日得财，次日再占，神不告已问之事而报申日破财（c16，见《增删卜易》序）**
- 遇到什么问题：作者占求财得旺财持世，自己已明知辰日得财，第二天仍就同一件事再占一卦，得"申金兄动而不得"，与首卦直接矛盾，两卦到底算谁的。
- 怎么用这个方法论：回到占前的念头纯度上重新归因——前一卦已经分明，本不该再渎；既然已分明还再问，卦不再回答已经问过的事，转而去报没被问过的事。
- 得出什么结论：两卦各应一事，辰日得财属实；"申金兄动"指向的是另一件未问之事。
- 实际结果如何：辰日果然得财，到申日因别的事破财。

**其二｜占母亲"何时来"，同一卦里是否该兼问平安（c17，卷四《行人章》第九十四）**
- 遇到什么问题：酉月戊申日占母亲在外何时来，卦成之后那爻被月建日辰和动爻一起冲克，看着像大凶之兆。
- 怎么用这个方法论：严守"一卦只答一问"——问的是"来不来"，就只论那爻是否伏藏、是否受制于外力，不顺手兼论生死安危。
- 得出什么结论：受克而且伏藏，断为不来。
- 实际结果如何：其后果然在外平安，未归也并无灾祸——证明当时若顺手兼断平安就会错。

**其三｜占丈夫"是否还往他省去"，凶象转成吉断（c19，卷四《行人章》第九十四）**
- 遇到什么问题：亥月甲子日妻占在外之夫是否还要去别省，代表丈夫的那一爻被他爻发动所克，旁人以"主事之爻有病，别问归期"来质疑。
- 怎么用这个方法论：先校正问目再取符号方向——若问的是平安，受克就是不利；但问的是"是否还要往别处去"，受克恰好表示受制于外因而动不了，也就是不去他乡。
- 得出什么结论：不往他处，不日必回，应在合住那条克爻的巳日到家。
- 实际结果如何：果于巳日到。

## A2 — Future Trigger（何时被调用）

1. **用户准备为一件事起卦，正要摇第一枚铜钱。** 用户会说："我想占一卦看看这事成不成"/ "帮我起一卦" / "I want to cast a hexagram" / "should I do it"。**trigger 词：起卦 / 占一卦 / cast a hexagram / divination question**。此时必须先走本卡：把诉求收敛成单句问话。
2. **用户一口气抛出两个以上诉求，想一卦解决。** 用户会说："我顺便再问问我妈身体" / "顺便看看今年财运" / "can I ask two things in one cast"。**trigger 词：双念 / 一卦多问 / multiple questions in one cast / two thoughts**。这是典型的双念，必须拆成两次占问。
3. **用户想让别人替自己占。** 用户会说："我让我老婆替我摇一卦行不行" / "帮我朋友占一下" / "can someone cast for me"。**trigger 词：代占 / 让我老婆替我摇 / proxy casting / cast on my behalf**。触发"我事必亲占"的硬规定。
4. **用户想替子女、下属、亲友问一件事。** 用户会说："帮我儿子问问这次考试" / "替我同事占占他那个 offer" / "ask for my friend"。**trigger 词：替某人占 / 帮我儿子问 / asking on behalf of others / third-party query**。触发"他事由他动念"的处置程序。
5. **问题过于笼统。** 用户会说："我今年运势怎么样" / "我这道坎过得去吗" / "tell me about my year"。**trigger 词：流年 / 运势 / vague question / general fortune reading**。触发"须指其事而占"，要求切成可判是非的具体项。

**与相邻能力的区分：** 本卡处在**同一次占问的最前端**，负责"还没摇之前怎么问"；`qigua-zhuanggua` 负责摇完之后把铜钱结果排成卦单；`qu-yongshen` 负责在卦单上选落点；`fenzhan-duozhan` 负责卦已经出来却仍不确定时要不要多摇几次。**顺序上本卡一定在最前，一旦开始摇卦，本卡的职责即告结束。**

## E — Execution（可执行步骤）

1. **把诉求改写成一句话问句。** 只能有两种形态：是非题（"这件事成不成"）或时间题（"什么时候应"）。
   - 完成标准：这句话能被直接回答"是"或"否"，或者能落到一个时间点上；写成 20 字以内记下来。达不到就继续改写。
2. **检查是否混进了第二个诉求。** 逐字读一遍刚写的那句话，数里面的动词和宾语。
   - 完成标准：句中只出现**一个**待判定的结果。出现第二个（例如"成不成"+"干得久不久"、"我能拿到吗"+"我妈身体如何"）就拆成两句，各自单独处理。
3. **确认这次念头由谁生出。** 问自己三问：这件事是我自己的事吗？若是，是不是我自己在这儿摇？若是别人的事，是不是他自己起念要问的？
   - 完成标准：能点名说出"这次的念头出自某某本人"。三种不成立的情况按如下处理——我事别人代摇→停止，改由本人自己摇；他人之事由我提醒→停止，先把事由告诉对方，然后明确交代他此刻不要摇，等他把这事搁下一阵、忽然自己想起来再摇；再问也很难由本人出面上的，如实说明这一卦的代表性存疑，不要硬取代表爻。
4. **把问目写死并书面化。** 在纸上先记下占问当日的年月日辰，按六神章排好六神，再把第 1 步得到的那句唯一的问话一并写在旁边（此三事的体例见卷一《八宫图第三》）。
   - 完成标准：纸上同时具备三项内容——年月日辰、排好的六神、那句唯一的问话。
5. **判停点。** 上述四条有一条不满足，就**停下，不要起卦**，先回来修正：第 1 步没改成单句、第 2 步发现第二个诉求、第 3 步念头归属说不清、第 4 步三项内容缺任一项，均属于"不许摇"。只有五条全部通过，才允许进入 `qigua-zhuanggua`。

## B — Boundary（边界）

### 1. 不要用这个能力的场合（反场景）

- **纯事实查询**：用户问的是可以查证的事实（列车时刻、政策条款、某种药物的说明书、某公司地址），应当让他去查，不要起卦。这类问题本就不属于本书方法的适用面。
- **卦已经摇出来了才发现不对**：那是 `fenzhan-duozhan`（要不要分占/多占）和 `zhanci-yingbi`（是不是这一卦其实在答复另一件事）的活儿，不要再退回本卡浪费一轮。
- **卦已经排好、要讨论哪一爻代表所问之事**：交给 `qu-yongshen`；本卡不处理选爻，也不处理旺衰（`sishen-wangshuai`）、应期（`yingqi-tuiduan`）。
- **用户是在追问某一卦已经说完的结论对不对**：属于复盘，不属于提问规范。

### 2. 作者在书里警告过的失败模式

- **x18｜心怀两三事而一卦求之，卦必乱应。** 书里的实例是先占求财、又占岳丈之病，结果前卦应了病、后卦反去应财。作者本人的断语是"半夜求神，亦有错矣"。
- **x19｜我事命人代占，取用神必错。** 某位在任官员叫家里人替自己占防灾，若按"家人占主"去取那两个身份爻会断成有险，实际那一卦响应的是官员自己的念头。作者的结论："我事必要亲占，命他人而代者，难取用神，必于不验。"
- **x22｜泛问而不指实。** 问雨要先说占本乡还是本省，问买卖要指明哪一处货、哪一处地头，否则"卦无所指"。作者反复强调"指其事而占者无不验"。

### 3. 作者的局限（来自阶段 0 批判）

- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

### 4. 安全边界

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。

## 相关能力

- `qigua-zhuanggua`（起卦与装卦六步）——**依赖/后继**：本卡产出合格问句之后，才轮到它把铜钱结果排成卦单。
- `qu-yongshen`（取用神）——**依赖/后继**：提问不清时这一步必然选错爻；本卡是它的前置校验。
- `fenzhan-duozhan`（分占与多占）——**组合/边界**：本卡负责"事前拆成几句问话"，它负责"事后决定要不要多摇几卦"，两者共同处理同一个"不确定性"。
- `zhanci-yingbi`（占此应彼 / 占远应近）——**风险来源**：本卡执行得越不严格，越容易触发"卦其实在答复别的事"这种事后解释。
- `pimiu-fanmoshi`（辟谬与反模式清单）——**对比**：它清理的是规则层面的错误，本卡清理的是提问层面的错误。
