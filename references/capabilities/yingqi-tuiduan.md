# 应期推断十二条

## R — Reading（原文）

> 卷一 各门类应期总注章

静而逢值逢冲：如主事爻临子水不动，后逢子日午日而应之，余仿此。动而逢合逢值：如主事爻临子水发动，后遇丑日子日而应之，余仿此。太旺者逢墓逢冲：如主事爻临午火，又遇巳火午月日占卦，或卦中巳午爻太多，后逢亥子日应之，又有戌日应之乃火入墓也，余仿此。

> 卷一 各门类应期总注章（末段）

勿谓爻之不验，远近当分：远事定之以年月，近事应之于日时。再问有占远应近，占近应远，占月应年，占日应时，亦所当知。倘遇卦之不明，再占是一法。卦有恍惚者，再占一卦，不可妄断。

## I — Interpretation（自述）

这张卡只回答一个问题：**既然吉凶已经定了，它什么时候发生。**

前提必须说死：**先有向背，才有早晚。** 吉凶没断出来就去推日期，等于在不知道结果的情况下猜时间——那时该做的是回 `sishen-wangshuai` 定吉凶、回 `daxiang-geju` 看格局。

作者给的这套解法，思路不是"另起一套术"，而是**给用神的每一种"病"配一味"解药"**：用神现在处于什么受阻状态，就找把这个状态解除掉的那一天。用神不动 → 等它值日、或等被冲；用神发动 → 等逢合、或等逢值；太旺 → 等入墓、或等被冲；衰绝 → 等遇生、遇旺之令；入墓 → 等冲开墓库；被合住 → 等冲开；月破 → 等填实、或等逢合；旬空 → 等填实、或等冲空。一句话：**先把用神推回"无病"状态，那一天就是应期。**

十二条总纲（规则名 / 触发条件 / 推导法）：

| # | 规则 | 触发条件 | 推导法 |
|---|---|---|---|
| 1 | **静而逢值逢冲** | 主事爻安静不动 | 后逢该爻地支值日，或逢与之相冲之日而应（如临子水不动 → 子日或午日） |
| 2 | **动而逢合逢值** | 主事爻发动 | 后逢与之六合之日，或逢该爻值日而应（如临子水动 → 丑日或子日） |
| 3 | **太旺者逢墓逢冲** | 用神极旺，或同类爻太多 | 后逢克制它的日（午火太旺 → 亥子日），或逢它入墓之日（火墓戌 → 戌日） |
| 4 | **衰绝者遇生遇旺** | 用神休囚无气或值绝 | 后逢生它的五行之月日，或逢它当令的季节（金衰于巳午月日 → 逢土月日或秋令） |
| 5 | **入三墓俱喜冲开** | 用神入日墓、动墓、化墓 | 后逢冲开墓库之日（火墓于戌 → 逢辰日） |
| 6 | **遇六合亦宜相击** | 用神与月建作合，或动而化合 | 吉凶必待冲开之月日（主象临子与丑合 → 逢午未日） |
| 7 | **月破喜填** | 用神被月建冲（月破） | 后逢破而逢合之日（子月午火破 → 未日），或逢填实之月（午月）则不破 |
| 8 | **旬空最爱填冲** | 用神值旬空（非真空） | 出空之日而应，或日辰冲空之日而应 |
| 9 | **大象吉而受克，须待克神受克** | 大象吉，但用神被克 | 等克用神的那一方自己受克之日（辰土用神被寅卯克 → 逢申酉日冲克克神则吉） |
| 10 | **大象凶而受克，须防克者逢生** | 大象凶，且用神被克 | 克神逢生之日即凶（同上例 → 逢寅卯亥日则凶） |
| 11 | **化进神逢值逢合；化退神忌值忌冲** | 用神化进或化退 | 化进：应所化之支值月日，或应与之相合之月日（申动化酉 → 申月日或巳月日）；化退：应退到之支的月日，或应冲它的月日（酉化申 → 申月日或寅日月） |
| 12 | **动爻、变爻皆可为应期** | 卦有动爻及其变爻 | 动爻与变爻各自都可能成为应期坐标（爻临戌土变出酉金 → 有应戌日者，有应酉日者） |

第 11 条之外还有一条独立的时间单位选择器，与前十二条并称"远近当分"：**远事定之以年月，近事应之于日时**。作者同时承认错位是常事——"占远应近、占近应远、占月应年、占日应时"。

补充两条：世爻空而元神动，须待元神逢值之日；世爻衰而元神静，须待元神逢冲之日。另可参"独发独静"，但作者明言**独发独静只能事后印证，不能事前代替用神**（见 B 段 x10）。

**最有价值的一点：多规则冲突时怎么合成。** 当同时命中两条方向不同的规则——例如用神既旬空（第 8 条）又被日辰合住（第 6 条）——**两个条件必须先后都满足**。先满足者是"事有转机 / 开始松动"之日；**二者皆满足之日**才是"事成 / 事应"之日。不要把两个候选日期挑一个了事，也不要取平均。若推演下来仍含糊，作者给了兜底条款：**"卦有恍惚者，再占一卦，不可妄断。"**

## A1 — Past Application（书中案例）

**1. 未月庚子日占求财，用神两现，反取旬空者定应期**（卷二 两现章第三十二，风天小畜）
- **遇到什么问题**：卦中两个妻财爻——应爻未土临月建（旺、不空），世爻辰土值旬空。古法规定"舍其旬空，用其不空"，照古法应当取未土为用神，应期也就该落在未土上。
- **怎么用这个方法论**：作者反用古法，按自己的验例"应乎旬空月破，舍其不空而用旬空"，取辰土为用神。随即套第 8 条"旬空最爱填冲"——应期落在辰土出空之日。
- **得出什么结论**：财必得（应爻临月建之财克世）；作者先推"次日辛丑冲动未财日得"，随后改判辰土出空之日。
- **实际结果如何**：得财，但**得于辰土出空之日**，而不是先前推的辛丑日——反证取空爻为用、按出空定应期才是对的。

**2. 未月甲午日占升迁，官星两现一空一破，取"实空实破"之年**（卷二 两现章第三十二，地水师变风水涣）
- **遇到什么问题**：问升迁。世爻极旺（临日建，又得月令作官星合世），但卦中两个官鬼爻一个旬空、一个月破，都不"可用"，两现取用神陷入僵局，应期更无从下手。
- **怎么用这个方法论**：不取现成的旺爻，而把"空"和"破"当作待时标志——按第 8 条（旬空填实）与第 7 条（月破喜填）取应期锚点，定在官星出空之年；同时用**外卦反吟**读时间曲线（去而复来）。
- **得出什么结论**：辰年官星出空一定高升，但反吟主反复，会"去而复来"。
- **实际结果如何**：果于辰年调河南，五月因他故又调回楚，十月升督府——十年间两调一升，**皆应实空之年**。

**3. 亥月丙午日母占子何日脱厄，三子孙爻独取月破者**（卷二 两现章第三十二，雷地豫变雷泽归妹）
- **遇到什么问题**：卦中三个子孙爻都生世爻，其中午火临日建而静（看似最强），另两爻巳火逢月破（看似最弱）。按常法应取临日建的午火，那应期就该落在午年。
- **怎么用这个方法论**：取逢月破的巳火为用神，套第 7 条"月破喜填"——应期落在**实破之年**（巳年）。作者并说明自己敢于许巳年而非午年，是因为合参了此前同一家人的另外两卦（长公自占申金子孙发动应巳年、弟占兄申金兄动亦应巳年）。
- **得出什么结论**：许巳年脱厄，即实破之年。
- **实际结果如何**：果脱厄于巳年。

**4. 辰月戊子日占父何日归，父母持世破而化空，作者反断"必归"**（卷二 月破章第二十七，乾为天变泽天夬）
- **遇到什么问题**：父母爻持世、值月破、又化旬空，既无日生又无动助。按古法"用神无气"，结论是其父不能归。
- **怎么用这个方法论**：先辟古法之谬——月破不是终局，发动就有祸福之基。再拆成两段应期：音信一段按第 7 条"破而逢合"（逢合之日得信）；归家一段按第 8 条，取化出之爻未土**出空之日**。并以朱雀临父动而持世佐证"有音信"（六神只作类象，不作吉凶）。
- **得出什么结论**：卯日有信，午未日必归。
- **实际结果如何**：果于卯日得信，乙未日到家。应卯日者破而逢合之日；应未日者父化未土出空之日。

## A2 — Future Trigger（何时被调用）

1. **吉凶已经断完，用户接着问"什么时候""哪天/哪月/哪年"。**
   用户会说："什么时候应" / "何日" / "哪年能成" / "应期怎么推" / "when will it happen" / "ying qi / timing"。
   *区分*：吉凶尚未断出 → 先 `sishen-wangshuai`，格局未扫 → 先 `daxiang-geju`；本卡**只回答时间**。

2. **已有断语，但对不上实际应在何时（断对了吉凶、断错了时间）。**
   用户会说："说是吉但一直没发生" / "我推的是这天，结果不是" / "predicted auspicious but nothing happened"。
   *区分*：先排查是否时间单位选错（远事用年月、近事用日时），再排查是否漏了第 12 条的错位（占远应近 / 占近应远）；若怀疑根本不是这件事，转 `zhanci-yingbi`。

3. **卦里有旬空、月破、入墓、被合住，不知道按哪条推。**
   用户会说："出空之日是哪天" / "实破之年是哪年" / "冲开墓库是什么时候" / "被合住怎么算" / "xunkong / yuepo / chong kai mu ku"。
   *区分*：单条命中 → 本卡直接推；**两条以上同时命中且方向不同** → 用本卡的"先后满足"合成逻辑，排不出先后则停（见 E 第 6 步）。

4. **用神化进化退，用户问该按哪一天算。**
   用户会说："化进神什么时候应" / "化退是不是就拖到那时候" / "jin shen / tui shen timing"。
   *区分*：进退的成立条件（进退四法）在 `daxiang-geju`；应期坐标（逢值逢合 / 忌值忌冲）在本卡。

5. **应期推到互相矛盾、无法排先后。**
   用户会说："两条规则算出来的日子不一样" / "到底哪个准" / "two rules give different dates"。
   *区分*：这正是本卡与 `fenzhan-duozhan` 的交界——先按"先后满足"合成；仍含糊则**停止硬凑**，转 `fenzhan-duozhan` 再占一卦。

## E — Execution（可执行步骤）

**1. 确认吉凶已定。**
- 动作：先取得一句明确的吉凶断语（来自 `sishen-wangshuai` 的加权结论 + `daxiang-geju` 的大象性质）。
- 完成标准：能复述"此占为吉 / 为凶"，且能指出是用神/元神/忌神中的哪一条支撑了这个结论。
- **判停点**：说不出来 → 停止本卡，回 `sishen-wangshuai`；若大象未扫 → 回 `daxiang-geju`。**吉凶未定不得进入第 2 步。**

**2. 判定事之远近，选定时间单位。**
- 动作：问清这件事的固有尺度（日内事 / 月内事 / 年计事），按"远事定之以年月，近事应之于日时"选择单位；并在结论里预留错位说明（占远应近、占近应远、占月应年、占日应时皆为常事）。
- 完成标准：写出一句"本占用 **__（年/月/日/时）** 为单位"。

**3. 用神状态扫描（逐项打勾，不留空）。**
- 动作：对用神逐项判定——□ 静 / □ 动；□ 旺 / □ 衰 / □ 太旺；□ 旬空（真空还是假空）/ □ 月破；□ 入日墓、动墓、化墓；□ 被合住（与月合、动而化合、与日月动爻合）；□ 化进 / □ 化退；□ 受克（克神是哪一爻、旺相否）。
- 完成标准：八项全部打勾完成，每项只填一个状态。

**4. 逐条匹配十二条，列出命中的所有规则及其候选日期。**
- 动作：把第 3 步的每个"病"对照十二条找"解药"——静→第 1 条；动→第 2 条；太旺→第 3 条；衰绝→第 4 条；入墓→第 5 条；被合住→第 6 条；月破→第 7 条；旬空→第 8 条；大象吉而被克→第 9 条；大象凶而被克→第 10 条；化进/化退→第 11 条；动爻与变爻→第 12 条。每条写出它推导出的具体日/月。
- 完成标准：输出一张"命中规则 → 候选日期"的清单，不少于一条，且每条都写清推导依据（例如"第 8 条：辰土旬空 → 出空之辰日 / 戌日冲空"）。

**5. 合成候选日期。**
- 动作 A（候选相同）：多条规则指向同一日/月 → 直接确定，并注明"三条并证"。
- 动作 B（候选冲突）：按**先后满足**逻辑处理——两个条件必须**先后都满足**；先满足者记为"事有转机 / 开始松动"之日，二者**皆**满足之日才是"事成 / 事应"之日。不可取其一，不可取折中。
- 完成标准：输出"松动日 = __；事应日 = __"两个字段（若只有一个条件则两字段相同）。

**6. 判停点：无法排出先后则停。**
- 动作：若第 4 步命中的规则互相矛盾、连"谁先谁后"都排不出来 → **停止推导**。
- 完成标准：写出一句"规则冲突、无法合成"，然后按作者兜底条款执行——**"卦有恍惚者，再占一卦，不可妄断"**，转 `fenzhan-duozhan`（次日洁诚再占，两卦合参）。**不得硬凑出一个日期。**

**7. 兜底与交付。**
- 动作：交付时同时给出——① 事应日/月；② 所依据的规则编号；③ 时间单位；④ 错位提示（可能占远应近）；⑤ 若仍含糊，明确建议再占。
- 完成标准：五项齐全；且**不**给出超出本占问题范围的确定性承诺。

## B — Boundary（边界）

**1. 不要用这个能力的场合（反场景）**
- 吉凶还没断 → 转 `sishen-wangshuai`；大象格局还没扫 → 转 `daxiang-geju`。本卡是主链路的最后一棒，不能插队。
- 用户问的是"成不成""吉不吉" → 转 `sishen-wangshuai`，本卡只答时间。
- 卦中乱动、内外竞发、规则冲突到无法合成 → 转 `fenzhan-duozhan` 再占。
- 卦与所问之事对不上（断语怎么都落不到这件事上） → 转 `zhanci-yingbi`，不要靠调日期去凑。
- **纯 factual 查询不该起卦**：考试放榜日期查官方公告、物流到货查运单、开庭日期查法院通知、天气查气象预报；这些直接查事实，不要用卦推日期。

**2. 作者在书里警告过的失败模式**
- **x07 信"避空"论，以为用神旬空就能躲过忌神之害**：作者斥其"悖也，谬也"——忌神动而用神空者，**出空之日逢殃**；元神动而用神空者，出空之日而得。唯一例外是**近病逢空**（出空即愈，不论克），他占皆忌。
- **x10 舍用神而执"独发 / 独静"断应期**：作者承认独发独静"亦有验也"，但那是"验事应之后"的印证，不能事前执之；"如舍其用神，执之而决事者，谬也，过也"。应期一律归用神。
- **x11 信古法"动逢月破、化空破谓之不进不退"，因而错判进退应期**：改用进退四法，化空者待出空、化破者待实破之日月而应。
- 另需注意：作者自述占雨一例中初断只能在两个候选日间摇摆，他的处理是"不难，再占一卦"——**候选日期摇摆本身就是触发再占的信号**，不是继续猜的信号。

**3. 作者的局限（阶段 0 批判，四条例行）**
- 全书所有"应验"案例都是**作者自己挑选并记录的**，没有对照组、没有失败率统计——这是幸存者偏差。吉凶断对而时间断错的例子，同样不会被系统性地记录下来。
- "占此应彼 / 占远应近 / 灵机变通"构成事后解释机制，使规则原则上无法被证伪；尤其"占远应近、占近应远、占月应年、占日应时"这条，等于给任何时间错判都准备了解释。
- 案例全部是清代前现代社会事务（科举、援例、世职、六畜、茔葬、痘疹），用到现代问题必须先做事类转译，时间单位的选择也会随之改变（古人的"远事"尺度与现代不同）。
- 六爻属于传统数术与民俗知识体系，**不是**现代科学意义上的预测方法。作为文化遗产研究、自我反思的启发式工具、创作素材有其价值；作为事实预测工具，没有任何可靠的实证支持。

**4. 安全边界**

> **不得用于**医疗诊断与用药建议、法律后果预判、金融投资决策、人身安全与刑事风险评估。用户拿这类问题来问，必须明确说明本书方法不能作为决策依据，并引导至专业渠道（医生 / 律师 / 持牌顾问 / 警方）。本卡的"疾病""官讼""求财"等类目是清代文本语境，不可替代专业判断。

> **本卡另有硬性禁项**：**不得给出精确的医疗预后时间点**（何时痊愈、何时恶化、预期余寿）、**法律裁决日期**（何时宣判、何时执行）、**行情点位与价格时间**（何时涨跌、何时到某价位）。这三类一旦出现，必须停止推演并明确拒绝，转而引导至专业渠道。
