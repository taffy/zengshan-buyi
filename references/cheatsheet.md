# 决策规则速查 — 增删卜易

| 能力 | 一句话规则 |
|---|---|
| 边界、拒绝与判停（安全红线） | 医疗、法律、金融、人身安全四类一律拒绝据卦下结论并引导专业渠道——触发后拒绝，不是不触发。 |
| 占前立意与提问规范 | 一念只占一事、我事必亲占、他事由他动念、须指实其事——四者任一不满足就不许摇卦。 |
| 起卦与装卦六步 | 摇卦记爻 → 定卦名（上卦在前）→ 纳甲装支 → 安六亲 → 定世应 → 排动变（变卦六亲仍照本宫）。 |
| 取用神（事类→爻） | 一切庇护我身者→父母，一切拘束我身者→官鬼，同类→兄弟，我所驱使之人/物→妻财，我所生养庇护者→子孙。 |
| 四神模型与四类作用力旺衰 | 用神之外只有四处能施力（月建/日辰/动爻/自变）；先清算四处再合成，用神无根则元神有力亦难生。 |
| 大象优先与格局判定 | 大象定性质、旺衰定程度——卦变回头克不看用神衰旺皆凶；六冲近病即愈、久病即凶。 |
| 应期推断十二条 | 先有向背才有早晚——静逢值冲、动逢合值、入墓喜冲开、月破喜填、旬空爱填冲，冲突时取"先后都满足"之日。 |
| 分占与多占（不确定性处理） | 事多头则分占，卦恍惚则多占，用神不现不取伏神——但卦已明现即不可再渎。 |
| 占此应彼 / 占远应近的重配对诊断 | 三条判据全中才改读（用神不在场 / 强烈指向无关爻 / 那事量级更大），否则判误读回到原问。 |
