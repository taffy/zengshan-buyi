## 步骤 1 — 结构（Structural）

### 一句话主旨

**六爻断卦的吉凶，不取决于卦辞、神煞或繁复古诀，而只取决于"用神"与四类作用力（月建、日辰、动爻、动变之爻）之间的生克制化与旺衰；凡卦象恍惚不明，就用"分占 / 多占"来消除不确定性，而不是靠玄解硬断。**

### 作者要解决的元问题

> "为什么同样学卜，有人百占百灵，有人百占不验？"

野鹤老人的答案是：**因为传世卜书里塞满了未经经验检验的教条**（卦身、身位、随鬼入墓、化气取用、冲散论、星煞独立断生死、伏神互卦……）。他自称四十余年"须臾不离"，逐条**试之—不验—删之**，只留下经得起反复验证的规则。书名"**增删**卜易"即此意：**删掉古法的伪规则，增入自己验过的规则**。

- **卷一（1–26 章）**：技术底座。八卦、八宫全图、浑天甲子、六亲、世应、动变、用神/元神/忌神/仇神、五行生克、四时旺相、月将、日辰、六神、六合、六冲、三刑、暗动、动散、卦变、反伏、旬空、生旺墓绝、应期总注、归魂游魂。

- **卷三（36–68 章）**：人生类应用。身命、终身财福、终身功名、寿元、趋避、父母寿元、兄弟、夫妇、子嗣、学业、求名、童试、科考、乡会试、升选、在任吉凶、援例、武试……求财。

## 步骤 2 — 解释（Interpretive）

### 关键术语词典（作者本人的用法，非字典义）

| 术语 | 作者用法 |
|---|---|
| **用神** | 所占之事对应的那一爻。占父以父母爻、占功名以官鬼爻、占财以妻财爻……"一切庇护我身者"为父母，"一切拘束我身者"为官鬼 |
| **元神** | 生用神之爻 |
| **忌神** | 克用神之爻 |
| **仇神** | 克元神而生忌神之爻 |
| **月建 / 月将** | 占卦之月地支，"万卜之提纲"，司三旬之令 |
| **日辰** | 占卦之日干支，"六爻之主宰"，四时俱旺，与月建同功 |
| **暗动** | 静爻**旺相**，被日辰冲之 → 暗动（有力）；静爻**休囚**被冲 → 日破（无用） |
| **旬空** | 该旬十日中所缺的两个地支。"旺不为空、动不为空、有日建动爻生扶者不为空" |
| **月破** | 月建冲爻。作者修正古法：动则不终破，"出月则不破，实破之日则不破" |
| **进神 / 退神** | 动爻化出同五行的递进/递退（亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌为进） |
| **回头生 / 回头克** | 动爻变出之爻，回过来生/克本爻。**回头克是全书最重的凶兆之一** |
| **六冲** | 子午、丑未、寅申、卯酉、辰戌、巳亥相冲；亦指八纯卦等十个六冲卦。**近病逢冲即愈，久病逢冲即凶** |
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未。"静逢合为合起，动逢合为合绊" |
| **反吟 / 伏吟** | 卦变回头冲克 / 伏而不动，主"成而败、败而成"的反复 |
| **飞神 / 伏神** | 用神不上卦时，从本宫首卦寻出伏于某爻之下。**作者主张不用伏神，改以"再占"取用神** |
| **分占** | 一事一卦。身命、财福、功名、夫妻、子嗣各占一卦，**严禁一卦兼断**（因父子财官各有相忌相伤） |
| **多占** | 卦象恍惚时，次日洁诚再占，两卦合参而断 |
| **神兆机于动** | 全书第一原理。动爻必有因，故"动不为空""动不为散""动必有祸福之基" |
| **大象** | 整体卦象吉凶。卦变回头克者，**不看用神衰旺，皆以凶推** |
| **独发 / 独静** | 五爻不动一爻动 / 五爻动一爻静。作者认为只可作应期参考，**不能代替用神** |
| **占此应彼** | 卦不应所问之事，而反应未问之事（神"舍小事而报大事"） |

### 核心命题（12 条，用我自己的话重述）

1. 断卦只需五个变量：用神，以及作用于它的月建、日辰、动爻、动变之爻。四处全生则吉，全克则凶，混合则看旺衰。
2. **旺衰优先于关系**。生扶再多，若用神"无根""制中弱主"，则"虽有如无"。
3. **动爻是信息的载体**。神兆机于动——静卦信息少，动卦信息多；动爻不可当空、不可当散。
4. **月建日辰是最高权重**。"日月如天"，能生克一切爻（含变爻、伏爻），而诸爻不能伤日月。
5. **用神无根则元神有力亦难生**。接续相生也救不回来（"如树无根，寒谷不回春"）。
6. **大象（卦变回头克）压倒用神衰旺**。巽变乾、离变坎这类回头克，"不论用神之衰旺皆以凶推"。
7. **六冲是双刃**：凶事宜冲散，吉事不宜冲；近病逢冲即愈，久病逢冲即死。
8. **旬空与月破是"待时"而非"终局"**。出空、实破、填合之日即应。唯一例外是"真空"。
9. **分占优于一卦兼断**。父子财官各有相忌，一卦兼断必然自相矛盾。
10. **多占优于玄解**。卦不明就再占，不要硬凑伏神、互卦、化气。
11. **星煞、六神、卦身、身位皆无独立断验权**，只在用神旺相时"附和"增吉增凶。
12. **一念只占一事**。心怀两三事而占者，卦必乱应（可能前卦应后事、后卦应前事）。

### 论证链与证据

作者的论证方式是**实证主义的**：提出规则 → 给出卦例（含月日、卦名、六爻装排、断语）→ 记录实际结果 → 若不符则修正或删除古法。

全书约 200+ 个完整卦例，绝大多数带"果于 X 日/年……"的应验记录。这是本书区别于其他卜书的核心特征——**它是一部带对照记录的实验日志**。

## 步骤 3 — 批判（Critical）★

### 3.1 时代局限

- **前现代问题域**：案例几乎全部是科举、援例买官、世职承袭、官府升迁、六畜、茔葬、痘疹、婢仆、纳宠。直接套用到现代问题（求职、签约、投资、诉讼、医疗）必须做**事类转译**，否则取用神就会错。
- **宗法与等级秩序内嵌**："占妻妾婢仆以妻财爻为用神""弟兄变鬼防手足之厄""财化鬼主伤克妻妾婢仆"——把人（妻、妾、婢、仆）与"财物"归为同一用神，是当时社会结构的投影，不是中性技术。
- **无概率与统计语言**：全部用"许之""果于""必""定"等确定性措辞，没有失败率、没有样本量。

### 3.2 立场盲点

- **职业卜者的权威建构**：作者靠"灵验"立信。书中收录的几乎全是应验案例，**没有对照组、没有失败记录**。这是典型的**幸存者偏差**——他删掉"不验"的古法，用的是个人经验判断，同样没有统计支撑。
- **"灵机变通"是万能补丁**：作者反复说"全在人之变通""神报吉凶之月日不可照样而书符"。规则可以被事后无限微调，则任何反例都无法推翻它。
- **"屡试"的可信度存疑**：作者自称"四十余年须臾不离"，但一个人的记忆与个案积累，无法区分真规律与巧合。三刑章里他自己承认"占过数十年只验得一卦"——这其实说明他的"验"标准相当宽松。

### 3.3 未被证明的假设

- **根本假设**：卦象与所问之事存在确定对应（"神告"）。全书从未论证此点，直接当作公理。
- **事后解释机制完备**："占此应彼""占远应近""舍小事而报大事""神不告已问之事者以重大者而先告"——这些机制共同构成了一个**不可证伪**的体系。卦不准时，永远可以归因于"神在报别的事"。
- **"多占"与"再三渎"的矛盾**：作者用"卦已明则不可再渎，卦恍惚则可再占"调和，但"卦是否明"本身就是主观判断，等于给"一直占到满意为止"留了口子（他自己也承认占功名占过七次）。

### 3.4 最强反对意见

> **一个允许"卦不应所问之事、而反应所未问之事"的系统，原则上无法被检验。** 加上"灵机变通""多占合参""占远应近"三套事后调节机制，这套体系对任何结果都能给出解释。它的价值不在预测精度，而在**提供一套自洽的、迫使人对处境做结构化梳理的符号系统**。

### 3.5 现代立场（必须写进每个 skill 的 Boundary）

六爻纳甲筮法属于**传统数术与民俗知识体系**，不是现代科学意义上的预测方法。它：

- 可作为**文化遗产 / 思想史 / 民俗学**的研究对象；
- 可作为**自我反思的启发式工具**（强制你列出关切、权衡利弊、设想时间尺度）；
- 可作为**文学、游戏、影视设定的素材**；
- **不可**作为医疗、法律、金融、投资、人身安全等重大决策的依据。任何此类使用都必须明确拒绝并引导至专业渠道。

## 步骤 4 — 应用潜力（Applicability）

### 可 skill 化的内容（框架 / 清单 / 决策程序）

| 候选 | 类型 | 说明 |
|---|---|---|
| 起卦装卦（摇卦 → 纳甲 → 六亲 → 世应 → 动变） | 操作流程 | 纯机械，可完全程序化 |
| 取用神（按事类选爻） | 决策表 | 卷一用神章 + 卷三卷四各门题头 |
| 旺衰评估（月建/日辰/动爻/动变四类作用力） | 算法 | 卷一核心 |
| 吉凶大象判定（生克制化 + 特殊格局） | 决策树 | 千金赋 + 各格局章 |
| 应期推断（十二条填实/冲开规则） | 清单 | 应期总注章 |
| 分占与多占（不确定性处理） | 流程 | 序 + 旬空章 + 飞伏章 |
| 识别"占此应彼 / 占远应近" | 诊断清单 | 千金赋末段 |
| 辟谬清单（作者删掉的错误规则） | 反模式清单 | 贯穿全书 |

### 不可 skill 化

- 具体门类的断语细节（茔葬、痘疹、博奕、马房猪圈……）— 太琐碎且时代性太强，降级为 reference 表
- 单个卦例 — 作为能力卡的 A1（书中案例）素材
- 六神/星煞的具体类象 — 作者自己说无独立断验权，降级为附注

### 预估

- **能力卡数量**：8–10 张
- **晋级为独立 Skill**：3–4 个（起卦装卦、取用神+旺衰大象断、应期推断）
- **优先级排序**（按"最能赋能使用者"）：
  1. 起卦装卦（不会这个，后面全免谈）
  2. 取用神 + 旺衰大象断（这是全书的心脏）
  3. 应期推断（最高频的实际需求）
  4. 分占多占 + 不确定性处理（最能体现野鹤的独门贡献）
  5. 辟谬清单（防错）
  6. 占此应彼诊断（高阶）
